# 022. Hue Purity and Brightness

**You make:** ~/Art/Design/022-three-qualities.kra (new file)
**Builds on:** lesson 021
**Time:** 35 min
**Read:** Color Problems (Vanderpoel 1903), PDF pages 48–49,165,167; Krita Manual, Advanced Color Selector; Krita Manual, Rectangle Tool

## The idea
Emily Vanderpoel, writing in 1903, says every color has three qualities. Hue is the name of the color, like red or green. Purity is how free it is of white, black, or other colors. Luminosity is how bright it is. Learn to change one quality at a time. Then you can say why a color looks the way it does.

> "The second quality or constant of colors is purity, that is, its lack of any mixture of white, black, or any other color." (Color Problems, PDF page 49)

## Look
Page 48 and 49: read the three qualities. Page 165, Plate III: see six spectral hues in a row. Page 167, Plate IV: see colors in order of brightness, then pure and grayed.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Open the Advanced Color Selector docker (Settings ‣ Dockers). Find its hue, saturation, and value controls.
3. Pick the Rectangle Tool. Set Fill to Foreground color.
4. Row 1, hue: make six squares across. Use violet, blue, green, yellow, orange, and red. Keep each one strong.
5. Row 2, purity: pick one hue. Make six squares, each more gray than the last. Lower the saturation.
   You should see the same hue get duller.
6. Row 3, brightness: pick the same hue. Make six squares from very dark to very light. Change the value.
7. Under each row, write the quality: "hue", "purity", "brightness".
8. Squint at row 1. Which hues look lightest? Which look darkest?
9. Write the lightest and darkest in a text line.
10. Press Ctrl + S. Save as ~/Art/Design/022-three-qualities.kra.

## Check your work
- Did row 2 change only the purity?
- Did row 3 change only the brightness?
- Which of your six hues looked brightest in the gray test?

## Make it yours
- Do the same with a hue you pick: your favorite.
- Make a leaf in three purities.

## New words
- **hue** — the name of a color, such as red
- **purity** — how free a color is of white, black, or gray
- **luminosity** — how bright a color looks
