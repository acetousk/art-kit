# 034. Type Specimen Poster

**You make:** ~/Art/Design/034-type-poster.kra (new file)
**Builds on:** lessons 030 to 033
**Time:** 45 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 63,83; Composition (Dow 1913), PDF page 65; Krita Manual, Text Tool; Krita Manual, Text Properties Docker; Krita Manual, Rectangle Tool

## The idea
A type specimen shows off one font. You will make a poster for one font family. Use display type big and bold. Use text type small and quiet. Add a hierarchy with three levels. Hass says titles carry flavor while text blocks must be easy to digest.

> "One function is to call attention to or to ‘display’ the intent of a communication." (Design Fundamentals, PDF page 63)

## Look
Hass page 63: re-read the two functions. Hass page 83: re-read Title, Subtitle, and Text block. Dow page 65: re-read how letters form a tone.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi. Save it as ~/Art/Design/034-type-poster.kra.
2. Choose one font family you like from your last lessons.
3. Pick the Text Tool. Type the name of the font very large at the top. This is the Title.
4. Under it, type the alphabet in capitals in one line. Set a medium Font Size.
5. Type the alphabet in lowercase and the numbers 0 to 9 below.
6. Type a short paragraph of 30 words in text size. Pick a size that you can read.
   You should see a clear gray block.
7. Set Line Height in the Text Properties docker so the lines are not too tight or loose.
8. Pick a second font with strong contrast. Use it for a subtitle line.
9. Add one color block behind the title with the Rectangle Tool.
10. Align all text to one left guide.
11. Squint. Is the order title, subtitle, then text?
12. Press Ctrl + S. Save as ~/Art/Design/034-type-poster.kra.

## Check your work
- Can you read the paragraph easily?
- Do you see three clear levels?
- Does the second font contrast with the first?

## Make it yours
- Make a second poster for a different font family.
- Put your name large in a display font and your bio in a text font.

## New words
- **specimen** — a sample that shows what something is like
- **line height** — the space between lines of text
- **leading** — another name for line height
