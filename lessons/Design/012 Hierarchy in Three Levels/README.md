# 012. Hierarchy in Three Levels

**You make:** ~/Art/Design/012-hierarchy.kra (new file)
**Builds on:** lesson 011
**Time:** 35 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 82–83; Krita Manual, Text Tool; Krita Manual, Text Properties Docker

## The idea
Hierarchy puts things in order of importance. The reader sees the first thing, then the second, then the third. Make levels clear by size, weight, color, and place. Hass says three levels are a good plan for text: a title, a subtitle, and a text block. More levels blur together. Small differences do not work.

> "A good strategy to follow with text design is to apply three levels of typographic hierarchy." (Design Fundamentals, PDF page 83)

## Look
Page 82: see the old newspaper-style page in Figure 3.29. Page 83: find the three headings Title, Subtitle, and Text block.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Plan a flyer for a school club. Choose a club name, one line about it, and a time and place.
3. Pick the Text Tool. Click at the top left and type the club name. This is the Title.
4. In the Text Properties docker, set a very large Font Size for the title.
5. Click below. Type the one line about the club. This is the Subtitle. Use a medium Font Size.
6. Click lower. Type the time and place in three short lines. This is the text block.
7. Use a small Font Size for the text block.
   You should see three clear sizes.
8. Pick the Shape Selection Tool. Align all three flush left with a guide.
9. Make the title darker or bolder than the rest by using the Font Style drop-down.
10. Squint. Is the order title, then subtitle, then text? Fix the size gaps if not.
11. Press Ctrl + S. Save as ~/Art/Design/012-hierarchy.kra.

## Check your work
- Can a person see the title first from across the room?
- Are the three sizes clearly different, not nearly the same?
- Is the text block quiet and easy to read?

## Make it yours
- Make a hierarchy for a lost-pet sign.
- Make a ticket for a movie night.

## New words
- **hierarchy** — an order of importance
- **title** — the big line that draws the reader in
- **text block** — the small body of information
