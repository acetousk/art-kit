# 036. Single Column and Multi Column Pages

**You make:** ~/Art/Design/036-columns.kra (new file)
**Builds on:** lesson 035
**Time:** 40 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 87–89; Krita Manual, Grids and Guides Docker; Krita Manual, Rectangle Tool; Krita Manual, Text Tool

## The idea
A page is rarely seen alone. In books and magazines, the two-page spread is the main unit of design. A single-column grid suits simple text. A multi-column grid gives more room for pictures and a complex order. Hang lines cut the page into sections across. Hass suggests the rule of thirds to place them.

> "In books and magazines, the two-page spread, not the individual page, is the main unit of design." (Design Fundamentals, PDF page 87)

## Look
Page 87, Figure 3.31: see a single column in the middle of the page. Page 88, Figure 3.32: see a three-column page. Page 88 and 89, Figure 3.33: see lines that cut the page across.

## Steps
1. Open Krita. Make a new document 3000 x 2000 px at 150 ppi. This is a two-page spread.
2. Choose View ‣ Show Rulers and Show Guides. Drag a guide to 1500 px for the middle fold.
3. Drag margin guides: 150 px from the top, bottom, left, and right edges. Add inner margins by the fold.
4. Left page: pick the Rectangle Tool. Draw one tall text block inside the margins. Fill it with gray.
5. Add a title with the Text Tool above the block. Align it flush left.
   You should see a calm, single-column page.
6. Right page: add guides for three columns, with a gap between each.
7. Draw a black picture box across two columns. Draw gray text blocks in the third column.
8. Add a hang line: place a horizontal guide one third down the page.
9. Start the picture box at that line.
   You should see a clear top zone and a content zone.
10. Add a title across the top zone with the Text Tool.
11. Compare the two pages. Which fits a poem? Which fits an article with a photo?
12. Press Ctrl + S. Save as ~/Art/Design/036-columns.kra.

## Check your work
- Is your single column held in place by white space?
- Can the picture span two columns on the right page?
- Does the hang line make a clear top zone?

## Make it yours
- Make a spread for a recipe book.
- Try four columns and see what changes.

## New words
- **spread** — two facing pages seen as one
- **gutter** — the inner margin at the fold
- **hang line** — a horizontal line that sections a page
