# 032. Slab Sans and Blackletter

**You make:** ~/Art/Design/032-slab-sans-black.kra (new file)
**Builds on:** lesson 031
**Time:** 35 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 63–64,68–69; Krita Manual, Text Tool; Krita Manual, Text Properties Docker

## The idea
Three more families have clear moods. Blackletter is heavy, dark, and old, from the first printed books. Egyptian, or slab serif, has thick square feet and came from the age of machines. Sans serif has no feet. It was first used only for titles, and later became the modern look.

> "it was only in the late 19th century that font designers began to consider removing serifs" (Design Fundamentals, PDF page 69)

## Look
Page 63 and 64: read about Blackletter and its dark color on a page. Page 68: read Egyptian. Page 69: read Sans Serif and the example font names.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Use the Straight Line Tool to divide the page into three bands.
3. Band 1: pick the Text Tool. In the Font Family list, pick a blackletter font.
4. If you have none, pick the heaviest, darkest font.
5. Type "Dragon Fair" in this font. Set it large. Add a short subtitle in a plain font.
6. Band 2: pick a slab serif font with thick square feet. Type "Farm Market" large.
   You should see a sturdy, friendly feel.
7. Add the subtitle in a light sans serif font.
8. Band 3: pick a clean sans serif font. Type "Robot Lab" large.
9. Add a small sans line for the time and place.
   You should see a clean, modern feel.
10. Use the Fill Tool to give each band a background color that suits it.
11. For each band, add one line saying why the type matches.
12. Press Ctrl + S. Save as ~/Art/Design/032-slab-sans-black.kra.

## Check your work
- Does the blackletter band feel old and heavy?
- Does the slab band feel sturdy?
- Does the sans band feel clean and modern?

## Make it yours
- Make a poster for a pirate day using one family only.
- Test: put "Robot Lab" in blackletter. Does the mood fit?

## New words
- **blackletter** — a heavy, dark, old style of type
- **slab serif** — type with thick, square feet
- **sans serif** — type with no feet
