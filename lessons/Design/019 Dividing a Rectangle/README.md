# 019. Dividing a Rectangle

**You make:** ~/Art/Design/019-rectangles.kra (new file)
**Builds on:** lesson 018
**Time:** 35 min
**Read:** Composition (Dow 1913), PDF pages 48–50; Krita Manual, Rectangle Tool; Krita Manual, Straight Line Tool; Krita Manual, Grids and Guides Docker

## The idea
Dow loved the rectangle because it can be cut in endless ways. The square and circle give few choices. He says good spacing comes from feeling, not from a formula. A few lines can divide a space into parts that fit together. Try this with your own lines.

> "the better the choice, the finer the art" (Composition, PDF page 48)

## Look
Dow page 48: read the first column about variation. Page 49: see the examples of rectangular line designs. Page 50: read about the Ca' d'Oro and the Japanese alcove, plate No. 31.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Pick the Rectangle Tool. Set Fill to Not filled. Draw a tall rectangle that fills most of the page.
3. Pick the Straight Line Tool. Draw one vertical line that splits the rectangle into two unequal parts.
4. Draw two horizontal lines across the wider part. Make the three parts unequal.
5. Draw one horizontal line across the thin part.
   You should see a set of different boxes that still fit.
6. Make the largest box black, with the Fill Tool.
7. Make a second copy of the design. Move the first vertical line to a new place.
8. Make a third copy. Use a curved line from the Bezier Curve Tool to change one cut.
9. Compare the three. Pick the one with the best spaces. Mark it with a star.
10. Pick the Text Tool. Add a small title below the best design.
11. Press Ctrl + S. Save as ~/Art/Design/019-rectangles.kra.

## Check your work
- Are your boxes all different sizes?
- Does the black box balance the lighter boxes?
- Can you say why your best version won?

## Make it yours
- Design a bookshelf front using only line cuts.
- Design a phone screen layout with four zones.

## New words
- **proportion** — how the sizes of parts relate
- **variation** — small changes made on one idea
- **spacing** — the choice of where lines fall
