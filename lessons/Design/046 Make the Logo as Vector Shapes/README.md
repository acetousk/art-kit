# 046. Make the Logo as Vector Shapes

**You make:** ~/Art/Design/046-logo-vector.kra (new file)
**Builds on:** lesson 045
**Time:** 45 min
**Read:** A Book of American Trade-Marks (Sinel 1924), PDF pages 5–6; Krita Manual, Vector Layers; Krita Manual, Shape Edit Tool; Krita Manual, Arrange

## The idea
A vector shape is made from math, so it stays sharp at any size. This is why logos are drawn as vectors. Sinel says a mark must be flexible and must keep its features at any size. In Krita you can build a mark on a vector layer. You can edit the nodes of any shape later. You can resize it for a sticker or a sign.

> "Flexibility, the ready adjustment to new conditions or requirements is next in importance" (A Book of American Trade-Marks, PDF page 5)

## Look
Sinel page 5: read the paragraph on simplicity and flexibility. Page 6: read the paragraph on irregular shapes.

## Steps
1. Open Krita. Make a new document 1800 x 1800 px at 150 ppi.
2. Add a Vector Layer. In the Layers docker, click the arrow next to +.
3. Open ~/Art/Design/045-mark-rough.kra. Copy your chosen mark. Paste it into this file as a reference layer.
4. Lower the reference layer opacity so it is faint.
5. On the Vector Layer, build the mark with the Rectangle, Ellipse, Polygon, and Bezier Curve tools.
6. Pick the Shape Edit Tool. Click a shape. Drag its nodes to smooth the curves.
   You should see clean, even curves.
7. Fill all shapes with black. Use Foreground color in Tool Options.
8. Hide the reference layer.
9. Pick the Shape Selection Tool. Select all shapes. Use the Arrange docker to group them.
10. Use the Transform Tool to make the group small, then big.
   You should see the edges stay sharp.
11. Press Ctrl + S. Save as ~/Art/Design/046-logo-vector.kra.

## Check your work
- Are all shapes on a vector layer?
- Do the curves look smooth and even?
- Do the edges stay sharp when large?

## Make it yours
- Make a second vector mark from your initials.
- Export a PNG with File ‣ Export for a friend.

## New words
- **vector** — a shape made of math, sharp at any size
- **node** — a point that controls a path
- **group** — shapes joined to move as one
