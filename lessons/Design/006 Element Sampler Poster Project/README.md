# 006. Element Sampler Poster Project

**You make:** ~/Art/Design/006-element-poster.kra (new file)
**Builds on:** lessons 001 to 005
**Time:** 50 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 55–57; Design Fundamentals (Hass 2015), PDF pages 60–62; Krita Manual, Vector Layers; Krita Manual, Text Tool; Krita Manual, Arrange

## The idea
Now use all five elements in one poster. Make a poster about your favorite animal. Use a focal point, lines, planes, texture, and clear negative space. Write a one-sentence message first. Then check every mark against that message.

> "Ambiguity creates tension, which increases the interest of a composition to the viewer" (Design Fundamentals, PDF page 60)

## Look
Page 55 to 57: review point, line, and plane. Page 60: read about active negative space. Page 62: read about pattern and texture.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi. Save it as ~/Art/Design/006-element-poster.kra.
2. Write your message in one sentence, such as "Owls see in the dark".
3. Type it small at the bottom with the Text Tool.
4. Add a Vector Layer. Use the Ellipse Tool and Polygon Tool to build your animal from three to six planes.
5. Fill each plane with the Foreground color. Use only three colors in all.
6. Add a Paint Layer. With a pencil brush preset, draw lines for details, such as whiskers or wing feathers.
7. Add one texture from lesson 004 inside one plane. Keep it away from the face.
8. Place one dot or small shape as the focal point, such as the eye.
   You should see the eye pull the look first.
9. Leave at least one third of the page empty. Check that the empty area has a clear shape.
10. Pick the Shape Selection Tool. Move the animal so the empty space is bigger on one side.
11. Add the title big with the Text Tool. Use the Text Properties docker for Font Size.
12. Squint at the poster. Remove one thing that does not support the message.
13. Press Ctrl + S. Save as ~/Art/Design/006-element-poster.kra.

## Check your work
- Can you point to the focal point in one second?
- Does the empty space look planned, not leftover?
- Does every part support your one-sentence message?

## Make it yours
- Make a second poster for a different animal with a different mood.
- Swap the texture. Does the animal feel warmer or colder?

## New words
- **composition** — how the parts of a picture are arranged
- **message** — the one idea a design must send
