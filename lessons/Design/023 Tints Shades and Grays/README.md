# 023. Tints Shades and Grays

**You make:** ~/Art/Design/023-tints-shades.kra (new file)
**Builds on:** lesson 022
**Time:** 35 min
**Read:** Color Problems (Vanderpoel 1903), PDF pages 61,173,175; Krita Manual, Advanced Color Selector; Krita Manual, Digital Color Mixer

## The idea
Vanderpoel names three scales for any hue. A tint is the hue with white added. A shade is the hue with black added. A broken tint, or gray tone, is the hue dulled with gray. Six steps in each scale are enough. These scales are the best tools for calm color schemes.

> "the normal hue mixed with progressive increments (additions) of white, thus forming tints" (Color Problems, PDF page 61)

## Look
Page 61: read the three numbered scales. Page 173, Plate VII: see the tint scales for each hue. Page 175, Plate VIII: see the shade scales.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Pick one hue in the Advanced Color Selector. Use a strong blue.
3. Pick the Rectangle Tool with Fill set to Foreground color. Draw six squares in a row.
4. Row 1, tints: from left to right, make each square lighter by adding white.
5. Row 2, shades: from left to right, make each square darker. Reduce value.
   You should see a smooth drop to near black.
6. Row 3, grays: from left to right, make each square duller. Lower saturation but keep the value.
   You should see the blue fade into gray.
7. Now repeat rows 1 to 3 with a second hue, such as orange.
8. Open the Digital Color Mixer docker (Settings ‣ Dockers). Look at how it mixes colors.
9. Label each row with the Text Tool.
10. Check that each step is the same size apart.
11. Press Ctrl + S. Save as ~/Art/Design/023-tints-shades.kra.

## Check your work
- Do the tints look like the hue plus white?
- Do the shades look like the hue plus black?
- Are the steps in each row even?

## Make it yours
- Make a sunset sky using only tints and shades of one orange.
- Make a dull gray-green set for a forest poster.

## New words
- **tint** — a hue with white added
- **shade** — a hue with black added
- **broken tint** — a hue dulled with gray
