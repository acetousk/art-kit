# 055. Build Your Portfolio Page

**You make:** ~/Art/Design/055-portfolio.kra (new file)
**Builds on:** all earlier lessons
**Time:** 45 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 48,50; Krita Manual, Layers Menu; Krita Manual, Text Tool; Krita Manual, File Menu

## The idea
A portfolio shows your best work and how you made it. Hass says sketches leave a paper trail that shows how an idea grew. Show it in a case study: the brief, the sketches, and the final work. Pick your six best pieces and set them on a grid.

> "Hand-drawn sketches provide a paper trail that shows your concept development process" (Design Fundamentals, PDF page 48)

## Look
Hass page 48: read the list of reasons to draw thumbnails by hand. Page 50: read the evaluation questions.

## Steps
1. Open Krita. Make a new document 3000 x 2000 px at 150 ppi. Save it as ~/Art/Design/055-portfolio.kra.
2. Pick your six best pieces from lessons 1 to 54. Include a poster, a logo, and a pattern.
3. For each file, open it. Choose File ‣ Export. Save a PNG copy with a short name.
4. In the portfolio file, choose Layer ‣ Import/Export ‣ Import Layer. Import each PNG.
5. Use the Transform Tool to make each image fit one cell of a 3 by 2 grid.
   You should see six pieces in a neat grid.
6. Set up the grid with the Grids and Guides docker. Snap each image.
7. Pick the Text Tool and click above the grid. Type your name and "Design Portfolio".
8. Use the Text Properties Docker to set the title size, color, and alignment.
9. Use the Text Tool to add a short caption below each piece.
10. In the top-right, add a small case study: three tiny images for the brief, the thumbnails, and the logo.
11. Use your brand colors from lesson 053 for the page background and the title.
12. Squint. Is there a clear order of reading?
13. Press Ctrl + S. Save as ~/Art/Design/055-portfolio.kra.

## Check your work
- Are the six pieces aligned on the grid?
- Does your page have a clear title and captions?
- Does the case study show how your idea grew?

## Make it yours
- Make a cover page for your portfolio.
- Pick which piece you are proudest of and give it a bigger cell.

## New words
- **portfolio** — a collection of your best work
- **case study** — a story of how a piece was made
