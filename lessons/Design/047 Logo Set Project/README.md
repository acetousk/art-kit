# 047. Logo Set Project

**You make:** ~/Art/Design/047-logo-set.kra (new file)
**Builds on:** lessons 043 to 046
**Time:** 55 min
**Read:** A Book of American Trade-Marks (Sinel 1924), PDF pages 5–6; Design Fundamentals (Hass 2015), PDF page 61; Krita Manual, Vector Layers; Krita Manual, Text Tool; Krita Manual, Layers

## The idea
A real logo comes as a set. It has the mark alone, the mark with a name, a one-color version, a reversed version, and a tiny version. Test it on several colors. Hass notes that designers use figure and ground to create meaning in symbols, wordmarks, and logos. Check that yours stays clear in every version.

> "Designers often utilize figure/ground in the crafting of symbols, wordmarks, and logos" (Design Fundamentals, PDF page 61)

## Look
Hass page 61: read the FedEx example. Sinel pages 5 and 6: re-read the note on simplicity.

## Steps
1. Open Krita. Open ~/Art/Design/046-logo-vector.kra. Save a copy as ~/Art/Design/047-logo-set.kra.
2. Make the canvas 3000 x 2000 px with Image ‣ Canvas Size.
3. Paste copies of your mark in six places. Size one big and one tiny, 64 px wide.
4. Version 1: the mark alone in black on white.
5. Version 2: mark and name. Pick the Text Tool and set the name in a font from lesson 032.
6. Place the name under the mark. Align both to the center.
7. Version 3: the mark in your main color on white.
8. Version 4: reversed. Draw a dark rectangle with the Rectangle Tool. Place a white mark on it.
9. Version 5: the tiny mark at 64 px.
   You should see if the tiny mark is still readable.
10. Version 6: put the mark on a busy pattern from lesson 049. Check that it still reads.
11. Fix any weak version. Simplify the mark if needed.
12. Label each version in small text.
13. Press Ctrl + S. Save as ~/Art/Design/047-logo-set.kra.

## Check your work
- Is the tiny version still clear?
- Does the reversed version work on a dark box?
- Do you have a one-color version?

## Make it yours
- Make a mark for a friend club as a gift.
- Make a stamp-sized version for a letter.

## New words
- **wordmark** — a logo made only of letters
- **lockup** — a mark and a name set together
- **reversed** — white on a dark background
