# 028. Color from Notan

**You make:** ~/Art/Design/028-notan-color.kra (new file)
**Builds on:** lessons 015 and 027
**Time:** 40 min
**Read:** Composition (Dow 1913), PDF pages 123–124; Krita Manual, Layers; Krita Manual, Blending Modes; Krita Manual, Freehand Brush Tool

## The idea
Dow says you can reach color through notan. Start with a design that already works in dark and light. Then swap the grays for hues of the same value. Light stays light and dark stays dark, so the picture keeps its strength. Good color depends on good notan, and good notan depends on good spacing.

> "substitution of hues for grays" (Composition, PDF page 123)

## Look
Dow page 123: read Color Derived from Notan and the exercise on the right. Page 124: read the next column about using bright and gray tones of one hue.

## Steps
1. Open Krita. Open the file ~/Art/Design/015-notan-landscape.kra.
2. Choose File ‣ Save As. Save a copy as ~/Art/Design/028-notan-color.kra.
3. Show only the "three values" layer. Hide the others.
4. Add a new Paint Layer above it. Set its Blending Mode to Multiply.
5. Pick a light yellow. Paint over the light sky area.
6. Pick a middle blue-green. Paint over the gray hill.
7. Pick a dark violet. Paint over the black areas.
   You should see color arrive, with the dark and light order kept.
8. Hide the color layer and show it again to compare.
9. Now make a second color layer. Use bright and gray tones of one hue only.
   You should see a calm, old-print look.
10. Pick the better version. Hide the other.
11. Press Ctrl + S. Save as ~/Art/Design/028-notan-color.kra.

## Check your work
- Did light areas stay light and dark areas stay dark?
- Did the picture keep its strong shapes?
- Did you use hues of the same value as the grays?

## Make it yours
- Make a color version of your notan poster.
- Try a warm version and a cool version.

## New words
- **value** — how light or dark a color is
- **hue** — the name of a color
- **substitute** — to put one thing in place of another
