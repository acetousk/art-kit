# 001. Design Is Choosing on Purpose

**You make:** ~/Art/Design/001-name-card.kra (new file)
**Builds on:** nothing
**Time:** 25 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 33–34; Krita Manual, Create New Document; Krita Manual, Vector Layers; Krita Manual, Text Tool

## The idea
Graphic design sends a message to a person. Before you draw, ask two questions. What is the message? Who is the audience? Then every shape, color, and word has a job. First, set up Krita and make a small name card.

> "The communication must carry a specific message to a specific audience on behalf of the client, and do so effectively" (Design Fundamentals, PDF page 33)

## Look
Page 33, the first two paragraphs under "Communication Design and The Design Process": find the words message and audience. Page 34: read about the "think small" car ad. One idea, said in a fresh way.

## Steps
1. Open Krita.
2. Press Ctrl + N for File ‣ New.
3. Set Width 1500 px, Height 2000 px, Resolution 150 ppi. Click Create.
4. Press Ctrl + S. Save the file as ~/Art/Design/001-name-card.kra.
5. In the Layers docker, click the arrow next to the + button. Choose Vector Layer.
   You should see a new layer with a vector icon.
6. Pick the Rectangle Tool in the toolbox. Drag one big rectangle in the middle of the canvas.
7. In Tool Options, set Fill to Foreground color. Pick a color in the Advanced Color Selector docker (Settings ‣ Dockers).
8. Pick the Text Tool and click inside the rectangle. Type your first name.
   You should see your name as editable text.
9. Select the text. Use the Text Properties Docker to set its size and color.
10. Use the Text Tool to add one word about you below, such as "drawing".
11. Resize and place both text objects inside the rectangle.
12. Check that the words contrast with the rectangle.
13. Ask yourself: what is my message? Who is my audience? Change one thing so the card fits.
14. Press Ctrl + S to save to ~/Art/Design/001-name-card.kra.

## Check your work
- Can you say the message of your card in one sentence?
- Did you pick the text color so it is easy to read on the rectangle?
- Did you choose each part of the card on purpose?

## Make it yours
- Make a second card for a different audience, such as a grandparent or a game club.
- Change only the colors. Does the message change?

## New words
- **message** — the one idea a design must send
- **audience** — the people a design talks to
- **vector layer** — a layer that keeps shapes sharp at any size
