# 008. Contrast and Scale

**You make:** ~/Art/Design/008-contrast-scale.kra (new file)
**Builds on:** lesson 007
**Time:** 35 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 72,74; Krita Manual, Rectangle Tool; Krita Manual, Ellipse Tool; Krita Manual, Transform Tool

## The idea
Contrast pairs two opposite things so that each looks stronger. Itten, a Bauhaus teacher, listed pairs like large and small, thick and thin, light and dark. Scale is the size of one thing next to another. Big differences feel dramatic. Small differences feel calm and professional. Use one kind of contrast most strongly.

> "If all the elements have the same visual weight, the composition will be flat." (Design Fundamentals, PDF page 74)

## Look
Page 72: read Itten's list of pairs, from large/small to diagonal/circular. Page 74: read the Scale paragraph and the "think small" idea.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Pick the Rectangle Tool. Draw four equal boxes in a 2 by 2 grid. Set Fill to Not filled.
3. Box 1, large and small: draw one huge circle and one tiny circle.
4. Box 2, thick and thin: draw one very thick line and one hair-thin line.
5. Box 3, light and dark: draw two squares. Make one nearly white and one nearly black.
6. Box 4, straight and curved: draw a hard zigzag next to a soft wave.
   You should see each shape look stronger beside its opposite.
7. Press Ctrl + Shift + S and save as ~/Art/Design/008-contrast-scale.kra. Next, make the scale test.
8. Add a new Paint Layer. Draw one tiny dot of red in the middle of a big empty area.
   You should see a tiny thing feel important in a big space.
9. Draw a second version on another layer. Place a huge shape that fills three quarters of the page.
10. Use the Text Tool to write "small difference" under a pair of nearly equal circles. Compare it to big difference.
11. Press Ctrl + S. Save as ~/Art/Design/008-contrast-scale.kra.

## Check your work
- Did each shape look stronger next to its opposite?
- Did the tiny dot in empty space get attention?
- Can you name one contrast that was strongest in your boxes?

## Make it yours
- Make a calm poster using only small scale differences.
- Make a loud poster using only big scale differences.

## New words
- **contrast** — a strong difference between two things
- **scale** — the size of one thing next to another
- **visual weight** — how strongly a shape pulls the eye
