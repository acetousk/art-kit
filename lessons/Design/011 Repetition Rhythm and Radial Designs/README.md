# 011. Repetition Rhythm and Radial Designs

**You make:** ~/Art/Design/011-rhythm-radial.kra (new file)
**Builds on:** lesson 010
**Time:** 40 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 79–80,90–91; Krita Manual, Multibrush Tool; Krita Manual, Straight Line Tool

## The idea
Repetition uses the same element again and again. Rhythm is how fast or slow the repeats come. Too much repetition becomes dull, so add a break. Hass also names radial design, where rays come from a center, like the sun. A dilatational design makes rings, like ripples in water. Krita can draw both for you.

> "Excessive repetition, however, creates monotony." (Design Fundamentals, PDF page 80)

## Look
Page 80: see the fish poster at the top, Figure 3.26, and read about repetition. Pages 90 and 91: read Radial and Dilatational.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Make a border. Pick the Rectangle Tool and draw one small square near the top left.
3. Copy it with Ctrl + C. Paste with Ctrl + V and move the copy right.
4. Paste again. Keep equal gaps between the squares.
5. Repeat until a row of eight squares crosses the page.
6. Make one square a different color, to break the rhythm.
   You should see the odd square become a focal point.
7. Add a new Paint Layer. Pick the Multibrush Tool (Q). In Tool Options, choose Symmetry mode.
8. Set the number of instances to 8. The axis should sit at the canvas center.
9. Pick a hard round brush. Draw a small curve near the center.
   You should see eight copies spin around the center like a flower.
10. Pick the Ellipse Tool. Draw five circles, each bigger than the last, from the same center. This is dilatational.
11. Use the Text Tool to label the rows: "repeat", "radial", "rings".
12. Press Ctrl + S. Save as ~/Art/Design/011-rhythm-radial.kra.

## Check your work
- Does your row of squares have an even beat?
- Does the odd square break the rhythm in a good way?
- Do the radial lines all start at one center?

## Make it yours
- Make a sun poster using radial lines only.
- Make a ripple pattern for a pond poster.

## New words
- **rhythm** — the beat of repeated parts
- **radial** — arranged like rays from a center
- **dilatational** — arranged in growing rings
