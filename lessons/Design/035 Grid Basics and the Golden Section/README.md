# 035. Grid Basics and the Golden Section

**You make:** ~/Art/Design/035-grid-basics.kra (new file)
**Builds on:** lesson 034
**Time:** 35 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 85–86; The Grammar of Ornament (Jones 1856), PDF page 14; Krita Manual, Grids and Guides Docker; Krita Manual, Snapping

## The idea
A grid is a hidden set of lines. It places things and makes them relate. Hass says a grid takes some choices off the table, so you can think about other parts. Plan the grid from the content. A poem book needs much white space, and a newspaper needs a tight grid. The golden section is one old grid.

> "A grid is a network of lines that structure the placement of elements and create relationships between them." (Design Fundamentals, PDF page 85)

## Look
Hass page 85: read the first paragraphs on Grid. Page 86, Figure 3.30: see the golden section drawn as rectangles with diagonals. Jones page 14: find Proposition 9 on proportion.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Open the Grids and Guides docker. Set X spacing and Y spacing to 125 px.
3. Turn on Show Grid and Snap to Grid.
4. Choose View ‣ Show Rulers. Drag guides to make margins about 125 px from each edge.
5. Pick the Rectangle Tool. Draw a title block that fills four grid cells across.
   You should see it snap to the grid.
6. Add a picture block with the Rectangle Tool. Make it 4 cells by 5 cells.
7. Add a text block next to it. Make it 2 cells wide.
8. Turn off Show Grid. Look at the page.
   You should see the blocks still look ordered.
9. Make a second copy of the page. Delete the blocks. Add two guides for the golden section.
10. Place a vertical guide at about 927 px and a horizontal guide at about 1236 px.
11. Put a small bright shape where the two guides cross.
12. Press Ctrl + S. Save as ~/Art/Design/035-grid-basics.kra.

## Check your work
- Did every block line up with the grid?
- Does the page still look ordered with the grid hidden?
- Does the shape at the golden point feel placed on purpose?

## Make it yours
- Make a grid for a book of poems.
- Make a grid for a tight news page and compare.

## New words
- **grid** — a hidden set of lines that guide placing
- **margin** — the empty border around the page
- **golden section** — a ratio of about 1 to 1.618
