# 020. Four Looks from History

**You make:** ~/Art/Design/020-style-cards.kra (new file)
**Builds on:** lessons 016 and 019
**Time:** 40 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 20,22–23,25; Krita Manual, Bezier Curve Tool; Krita Manual, Text Tool; Krita Manual, Rectangle Tool

## The idea
Designers copy ideas from old styles, so it helps to know them. William Morris wanted well-made, honest things with nature in them. The Werkbund and the Bauhaus used simple forms and machines. The Swiss Style used grids and clean sans type. You will make a card for each look. Use only what the pages say about it.

> "a fitness of purpose, truth to the nature of the materials and methods of production, and individual expression" (Design Fundamentals, PDF page 20)

## Look
Page 20: read what Morris wanted. Page 22: find the Werkbund motto. Page 23: find what the Bauhaus first year taught. Page 25: read the guiding ideas of the Swiss Style.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Draw two lines to make three equal bands. Each band is a card.
3. Band 1, Morris: use the Bezier Curve Tool to draw a curling vine with leaves.
4. Repeat the vine twice to make a border. Add a title in a serif font with the Text Tool.
5. Band 2, Bauhaus: draw a circle, a square, and a triangle with the Rectangle, Ellipse, and Polygon tools.
6. Use only red, yellow, blue, black, and white. Add a title in a plain sans font.
   You should see simple, bold, machine-like shapes.
7. Band 3, Swiss Style: place one big block of color on a guide.
8. Add a title flush left in sans type. Add a line of small type under it, also flush left.
   You should see strong order and much white space.
9. Under each card, write one fact from your Read pages in small text.
10. Look at all three cards. Which look would you pick for a bakery? For a robot club?
11. Press Ctrl + S. Save as ~/Art/Design/020-style-cards.kra.

## Check your work
- Does your Morris card use nature and curves?
- Does your Bauhaus card use only simple shapes and few colors?
- Does your Swiss card use flush left type and a clear order?

## Make it yours
- Redo the Morris card with a modern subject, like a phone.
- Choose a school club. Pick the style that fits it best and say why.

## New words
- **style** — a set of choices that give a certain look
- **sans serif** — a letter style with no small feet
- **grid** — a hidden set of lines for placing things
