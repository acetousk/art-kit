# 016. Notan Poster Project

**You make:** ~/Art/Design/016-notan-poster.kra (new file)
**Builds on:** lessons 007 to 015
**Time:** 55 min
**Read:** Composition (Dow 1913), PDF pages 71–72; Design Fundamentals (Hass 2015), PDF page 83; Krita Manual, Vector Layers; Krita Manual, Fill Tool; Krita Manual, Text Tool

## The idea
Now build a full poster with notan and the principles. Choose one subject, such as a flower, a cat, or a tree. Make three small thumbnails first, then pick the best. Work in flat black, white, and one gray. Use alignment, contrast, balance, and three text levels. Dow asks for a pattern of lines and spaces, not a copy of a flower.

> "Not a picture of a flower is sought" (Composition, PDF page 72)

## Look
Dow page 71: see how book covers use two tones. Page 72: read the flower exercise. Hass page 83: re-read the three text levels.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi. Save it as ~/Art/Design/016-notan-poster.kra.
2. Pick one subject, such as a flower. Choose a poster message, for example "Garden Club Sale".
3. Make three tiny sketches in one corner with a pencil brush preset.
4. Place the subject in a different spot in each sketch.
5. Choose the best one. Delete the others.
6. Draw the subject big, with lines that cut the page into uneven spaces.
7. Fill spaces with black, white, and one gray. Use the Fill Tool. Keep every area flat.
8. Check balance. If the page feels heavy on one side, move or add a shape.
9. Pick the Text Tool. Add a Title, a Subtitle, and a short text block. Set Font Size for each.
10. Align all text to one guide. Use Shift + S to snap.
11. Squint. Does one focal point win? Does the black form a clear shape?
12. Press Ctrl + S. Save as ~/Art/Design/016-notan-poster.kra.

## Check your work
- Are all your areas flat black, white, or the one gray?
- Is there one clear focal point?
- Are the three text levels clearly different and aligned?

## Make it yours
- Make a second poster using the same subject with the colors flipped.
- Make a poster for a nature walk.

## New words
- **thumbnail** — a very small first sketch
- **notan** — a design of flat dark and light shapes
