# 030. Type Is a Voice

**You make:** ~/Art/Design/030-type-voices.kra (new file)
**Builds on:** lesson 012
**Time:** 35 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 62–63; Krita Manual, Text Tool; Krita Manual, Text Properties Docker

## The idea
Type does two jobs. Display type calls attention to itself, like a title. Text type carries details and must be quiet and easy to read. Hass says type is like a tonal voice. It can sound serious, playful, exciting, or calm. Before you choose a font, say what voice your message needs.

> "Typography is the tonal equivalent of a voice and can be as personal or as general in flavour." (Design Fundamentals, PDF page 63)

## Look
Page 62: read the start of Typography and Figure 3.9. Page 63: read the two functions of type, display and text.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. Pick the Text Tool. Click near the top left and type the word "Hello".
3. Open the Text Properties docker (Settings ‣ Dockers). In the Paragraph tab, find Font Family. Choose a heavy, bold font.
4. Make a second "Hello" below. Choose a thin, light font.
5. Make a third "Hello" in a font with small feet on the letters (a serif font).
6. Make a fourth in a font that looks handwritten.
7. Make a fifth in a plain font with no feet (sans serif).
   You should see five voices from one word.
8. Next to each, write the voice in small text: "loud", "soft", "formal", "friendly", "plain".
9. At the bottom, write a short sentence of 12 words in a quiet text font. Set Font Size small.
   You should see that text type must be easy to read.
10. Pick the voice you would use for a school play poster. Circle it with the Ellipse Tool.
11. Press Ctrl + S. Save as ~/Art/Design/030-type-voices.kra.

## Check your work
- Do your five words sound different?
- Is your small sentence easy to read?
- Can you say which job display type does?

## Make it yours
- Write your name five ways and pick the one that sounds most like you.
- Write "STOP" in two voices, one polite and one loud.

## New words
- **display type** — type made to be seen first
- **text type** — small type made to be read easily
- **font** — a full set of letters in one design
