# 037. Modular Grid and Baseline

**You make:** ~/Art/Design/037-modular-grid.kra (new file)
**Builds on:** lesson 036
**Time:** 40 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 89–90,93; Krita Manual, Grids and Guides Docker; Krita Manual, Snapping; Krita Manual, Arrange

## The idea
A modular grid cuts the page into equal boxes both ways. Modules are like notes in a score. They give a layout a rhythm. A baseline grid is a set of horizontal lines that all type sits on. Both ideas are constraints. Hass says constraints help the designer focus on the message and not the structure.

> "The modules of this type of grid are always identical and are created by applying consistent horizontal and vertical divisions to the design space." (Design Fundamentals, PDF page 89)

## Look
Page 89, Figure 3.34: see the modular grid on a photo page. Page 90: read the Modular paragraph. Page 93: read the summary on design constraints.

## Steps
1. Open Krita. Make a new document 1500 x 2000 px at 150 ppi.
2. In the Grids and Guides docker, set X spacing and Y spacing to 250 px.
3. Turn on Show Grid and Snap to Grid.
   You should see 6 columns and 8 rows.
4. Pick the Rectangle Tool with Fill set to Foreground color. Draw a picture module that covers 4 by 3 cells.
5. Draw a small module of 2 by 1 cells beside it.
6. Draw a text module of 2 by 2 cells.
7. Draw a title module of 6 by 1 cells in a bold color.
8. Add three small square modules in a row, each 1 by 1.
   You should see all parts share one rhythm.
9. Fill the page so about a third stays empty.
10. Pick the Text Tool. Place text lines on every second grid line so the lines of text match.
11. Use the Arrange docker to Align Left on the modules that share a left edge.
12. Press Ctrl + S. Save as ~/Art/Design/037-modular-grid.kra.

## Check your work
- Do all the blocks sit on the grid?
- Did you leave some empty modules on purpose?
- Do the text lines sit on the same horizontal lines?

## Make it yours
- Make a calendar page with a modular grid.
- Make a bento box style poster.

## New words
- **module** — a fixed unit used in a larger system
- **baseline** — the line that letters sit on
- **constraint** — a rule that limits your choices
