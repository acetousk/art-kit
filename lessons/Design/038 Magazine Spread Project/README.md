# 038. Magazine Spread Project

**You make:** ~/Art/Design/038-spread.kra (new file)
**Builds on:** lessons 007 to 037
**Time:** 60 min
**Read:** Design Fundamentals (Hass 2015), PDF pages 85,88,93; Krita Manual, Grids and Guides Docker; Krita Manual, Text Tool; Krita Manual, Layers

## The idea
Design a two-page magazine spread about a topic you love, such as a pet, a sport, or a game. Plan the grid first. Then use hierarchy, alignment, contrast, balance, and a color scheme. Use a big picture drawn by you. Use short text blocks. Hass says visual systems create visual unity.

> "Visual systems create visual unity." (Design Fundamentals, PDF page 93)

## Look
Hass page 85: re-read why a grid comes from the content. Page 88: re-read the multi-column grid. Page 93: read the summary.

## Steps
1. Open Krita. Make a new document 3000 x 2000 px at 150 ppi. Save it as ~/Art/Design/038-spread.kra.
2. Write your topic and message in one sentence in a small text line at the top.
3. Make guides: margins, a fold at 1500 px, and a grid of 6 columns across both pages.
4. Make a hang line at one third of the height with a guide.
5. Draw a large picture of your topic on the right page. Use a Vector Layer.
6. Use a color scheme like the one from lesson 029.
7. Make a title in display type across the top. Make a subtitle under it.
8. Make two short text blocks in a text font. Snap them to the column guides.
9. Add one pull-quote in large type between two columns.
   You should see a second level of type.
10. Add a small caption under the picture. Align it to the picture edge.
11. Squint. Check the focal point. Check balance between the pages.
12. Fix one problem. Turn off the guides with View ‣ Show Guides to see the final page.
13. Press Ctrl + S. Save as ~/Art/Design/038-spread.kra.

## Check your work
- Does every element sit on the grid?
- Is there a clear hierarchy of title, subtitle, and text?
- Does the color scheme follow one dominant hue?

## Make it yours
- Make a second spread for the same topic with a different grid.
- Design a cover for the same magazine.

## New words
- **pull-quote** — a big quote taken from the text
- **caption** — a short line that explains a picture
