# 023. Check Camera Views

**You make:** add to 022-camera.blend (save as 023-camera-check.blend)
**Builds on:** lessons 002, 022
**Time:** 25 min
**Read:** Blender Manual, Camera View; Navigation (Flip View)

## The idea
Camera checks show how the picture will look. Quote: "The rendered image contains everything within the camera frame." Frame the room so the camera frame holds the main parts. Flip View mirrors the picture to check balance. Flip View does not change the camera.

## Look
Look at the dashed frame in Camera View. Look at the Frame Camera Bounds option in the View menu.

## Steps
1. Open the file from lesson 022.
2. Open the View menu. Go to Cameras. Choose Active Camera.
3. Check that the room fills the frame.
4. Open the View menu. Go to Cameras. Choose Frame Camera Bounds.
5. Open the View menu. Go to Navigation. Choose Flip View.
6. Look at the mirrored picture. Check the character position.
7. Choose Flip View again to go back.
8. Turn the camera with the Rotate gizmo in Object Mode if the room is off-center.
9. You should see: the room and character sit inside the dashed frame.
10. Save the file as ~/Art/3D Drawing/023-camera-check.blend.

## Check your work
- Does the room fill the frame?
- Did Flip View return to normal?
- Did you save the file?

## Make it yours
Make two checks. Use Flip View on each camera. Choose the one with better balance.

## New words
- **Framing** — choosing what the camera shows.
- **Balance** — how weight is spread across the picture.
- **Mirror** — show a picture reversed left to right.
