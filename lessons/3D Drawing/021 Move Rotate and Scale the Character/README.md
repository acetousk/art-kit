# 021. Move, Rotate, and Scale the Character

**You make:** add to 020-room-groups.blend (save as 021-character-place.blend)
**Builds on:** lessons 003, 020
**Time:** 35 min
**Read:** Blender Manual, Viewport Gizmos (Object Gizmos)

## The idea
Object gizmos move, turn, and size a whole object. Quote: "Object Gizmos allow mouse-controlled translation, rotation and scaling in the 3D Viewport." Use Move to set the location. Use Rotate to turn it. Use Scale to size it. Do this in Object Mode.

## Look
Look at the Gizmos popover in the header. It has three toggles: Move, Rotate, Scale.

## Steps
1. Open the file from lesson 020.
2. Open Object Mode from the Mode menu.
3. Add > Grease Pencil > Blank for the character. This makes a separate object.
4. In Draw Mode, draw a simple character on it. Then return to Object Mode.
5. Open the Gizmos popover in the header.
6. Turn on Move. Turn off Rotate and Scale.
7. Drag the Move gizmo arrow. The character moves.
8. Turn on Rotate. Drag the big circle. The character turns.
9. Turn on Scale. Drag the area between the two circles. The character gets bigger or smaller.
10. Press Ctrl-Z after each step to check the change.
11. You should see: the character stands inside the room.
12. Save the file as ~/Art/3D Drawing/021-character-place.blend.

## Check your work
- Does Move change only the location?
- Does Rotate turn the whole character?
- Did you save the file?

## Make it yours
Make a small copy of the character. Scale it to half size. Place it at the back of the room.

## New words
- **Gizmo** — a control on screen that moves or turns an object.
- **Location** — where an object sits in 3D space.
- **Scale** — how big an object is.
