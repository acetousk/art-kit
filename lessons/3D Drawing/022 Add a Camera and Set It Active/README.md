# 022. Add a Camera and Set It Active

**You make:** add to 021-character-place.blend (save as 022-camera.blend)
**Builds on:** lessons 002, 021
**Time:** 30 min
**Read:** Blender Manual, Camera View

## The idea
A camera shows the scene from one viewpoint. Quote: "The Camera View shows the scene from the active camera's viewpoint." Only one camera is active at a time. Make the camera active from the View menu. Then check the framing in Camera View.

## Look
Look at the View menu. Find Cameras. It has Active Camera and Set Active Object as Camera.

## Steps
1. Open the file from lesson 021.
2. In Object Mode, open the Add menu. Choose Camera.
3. Move the camera to the front of the room with the Move gizmo.
4. Select the camera in the viewport.
5. Open the View menu. Go to Cameras. Choose Set Active Object as Camera.
6. Open the View menu again. Go to Cameras. Choose Active Camera.
7. You should see: the viewport shows the camera view. A dashed frame shows the picture edge.
8. Save the file as ~/Art/3D Drawing/022-camera.blend.

## Check your work
- Does the dashed frame show the room?
- Is the camera the active camera?
- Did you save the file?

## Make it yours
Add a second camera on the other side. Make it active. Compare the two views.

## New words
- **Camera** — an object that sets the view for a picture.
- **Active camera** — the camera that the scene uses.
- **Frame** — the dashed edge of the picture.
