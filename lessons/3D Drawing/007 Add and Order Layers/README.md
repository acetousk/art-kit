# 007. Add and Order Layers

**You make:** ~/Art/3D Drawing/007-layers.blend
**Builds on:** lesson 006
**Time:** 30 min
**Read:** Blender Manual, Layers

## The idea
Layers keep parts of a drawing apart. Quote: "When you draw, the new strokes are added to the active layer." Each stroke belongs to one layer only. The layer at the top of the list is drawn above the others in the viewport. Put the room on one layer and the character on another.

## Look
Open the Object Data tab in the Properties editor. Find the Layers panel. The active layer is highlighted in the list.

## Steps
1. Open the file from lesson 006.
2. Open the Object Data tab in the Properties editor.
3. Find the Layers panel.
4. Click the Add New Layer button. A new layer appears.
5. Double-click the new layer name. Type Walls.
6. Draw a line. It goes on the Walls layer.
7. Click the first layer in the list. Draw a line on it.
8. Drag the Walls layer up or down in the list.
9. Open the Layer Specials menu. Choose Duplicate to make a copy of a layer.
10. You should see: the list has at least three layers.
11. Save the file as ~/Art/3D Drawing/007-layers.blend.

## Check your work
- Do new strokes go on the active layer?
- Can you reorder layers?
- Did you save the file?

## Make it yours
Make a layer named Sky. Draw a sun on it. Move Sky to the bottom of the list. See what changes.

## New words
- **Layer** — a group of strokes you can hide, lock, or move.
- **Active layer** — the layer that new strokes go into.
- **Duplicate** — make an exact copy.
