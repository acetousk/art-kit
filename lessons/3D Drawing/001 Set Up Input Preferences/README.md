# 001. Set Up Input Preferences

**You make:** no file. You change Blender settings only.
**Builds on:** nothing
**Time:** 20 min
**Read:** Blender Manual, Input (Preferences, Keyboard, Mouse, Tablet)

## The idea
Your device has no numpad. The pen has no middle button. Blender can change both. Set these options first. Then the other lessons work the same way for you. Blender can use the Alt key to act as the middle button.

Quote: "you can tell Blender to treat the standard number keys as Numpad keys" (Input, Keyboard).

## Look
The Input page has four parts: Keyboard, Mouse, Touchpad, Tablet. Only Keyboard and Mouse matter here.

## Steps
1. In Blender, open Edit > Preferences.
2. Click the Input section.
3. Under Keyboard, turn on Emulate Numpad.
4. Under Mouse, turn on Emulate 3 Button Mouse.
5. Keep Modifier set to Alt.
6. Read the warning under Emulate 3 Button Mouse. Alt-LMB now works as the middle button.
7. Scroll to Tablet. Do not change the Tablet API setting. It is for Windows only.
8. Close the Preferences window.
9. You should see: the Preferences window closes. The viewport is still open.

## Check your work
- Is Emulate Numpad turned on?
- Is Emulate 3 Button Mouse turned on?
- Do you know that Alt-LMB now works as the middle button?

## Make it yours
Hold Alt and drag with the pen in the viewport. Write down what the view does.

## New words
- **Numpad** — the group of number keys on the right of a keyboard.
- **Modifier** — a key you hold while you click or drag.
- **Emulate** — make one control act like another control.
