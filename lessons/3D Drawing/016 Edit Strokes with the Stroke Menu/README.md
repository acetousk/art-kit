# 016. Edit Strokes with the Stroke Menu

**You make:** add to 015-select.blend (save as 016-stroke-menu.blend)
**Builds on:** lesson 015
**Time:** 30 min
**Read:** Blender Manual, Stroke Menu; Introduction (Edit Mode)

## The idea
The Stroke menu changes many points at once. Quote: "The Stroke Menu is located in the header." Subdivide adds points. Simplify removes points. Use Simplify on a wobbly line to make it cleaner. Use Subdivide before you smooth a line with few points.

## Look
Look at the Stroke menu in the 3D Viewport header. It appears only in Edit Mode.

## Steps
1. Open the file from lesson 015.
2. Stay in Edit Mode. Choose the Strokes select mode.
3. Click a wobbly stroke on the back wall. It turns selected.
4. Open the Stroke menu in the header.
5. Choose Subdivide. More points appear on the stroke.
6. Open the Stroke menu again. Choose Simplify.
7. Read the Simplify options. Pick Fixed.
8. Press Ctrl-Z to undo the Simplify step.
9. You should see: the stroke has more points after Subdivide and fewer after Simplify.
10. Save the file as ~/Art/3D Drawing/016-stroke-menu.blend.

## Check your work
- Did Subdivide add points?
- Did Simplify remove points?
- Did you save the file?

## Make it yours
Subdivide a short stroke three times. Then use Simplify. Count the points at each step.

## New words
- **Subdivide** — add points between existing points.
- **Simplify** — remove points to make a stroke simpler.
- **Header** — the bar at the top of an editor.
