# 029. Edit Timing in the Dope Sheet

**You make:** add to 028-object-move.blend (save as 029-timing.blend)
**Builds on:** lessons 025–028
**Time:** 30 min
**Read:** Blender Manual, Dope Sheet, Grease Pencil mode

## The idea
The Dope Sheet shows each layer as a row of keyframes. Quote: "This mode lets you adjust the timing of a Grease Pencil object's animation frames." Move keyframes to change speed. Hide or lock a layer row to focus on one layer.

## Look
Look at the Dope Sheet. Each layer is a row. Each keyframe is a dot or block on the row.

## Steps
1. Open the file from lesson 028.
2. Change one editor to the Dope Sheet.
3. Set the mode to Grease Pencil.
4. Look at the row for each layer.
5. Click one keyframe on the ball layer.
6. Drag it one frame to the right.
7. Play the animation. Notice the change in speed.
8. Press Ctrl-Z to undo the move.
9. Click the lock icon on the Character row. It locks that layer.
10. Save the file as ~/Art/3D Drawing/029-timing.blend.

## Check your work
- Can you see one row for each layer?
- Did moving a keyframe change the timing?
- Did you save the file?

## Make it yours
Move every keyframe in the ball animation two frames later. Play it. Compare the speed.

## New words
- **Dope Sheet** — an editor that shows keyframes as rows.
- **Channel** — a row for one layer or object.
- **Timing** — when each frame appears.
