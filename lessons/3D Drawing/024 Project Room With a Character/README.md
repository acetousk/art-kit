# 024. Project: Room With a Character

**You make:** ~/Art/3D Drawing/024-project-room.blend (new file)
**Builds on:** lessons 001–023
**Time:** 60 min
**Read:** Blender Manual, Stroke Placement; Layers; Object Gizmos; Camera View

## The idea
Build one small scene. Use layers to keep parts apart. Quote: "Layers can be grouped using Layer Groups." Place the character object with gizmos. Set one camera. Check the picture in Camera View. Keep the file small. Use under 10 layers.

## Look
Look at the Layers list. Look at the Gizmos popover. Look at the dashed camera frame.

## Steps
1. Open Blender. Add > Grease Pencil > Blank.
2. Draw a floor and two walls with the Box tool. Use three planes, as in lesson 019.
3. Make a layer group called Room. Put the floor and walls in it.
4. Add > Grease Pencil > Blank for the character. This makes a separate object.
5. Draw a simple character on it in Draw Mode.
6. In Object Mode, use Move and Scale to place the character in the room.
7. Add a camera. Move it to the front of the room.
8. Set it as the active camera from the View menu.
9. Choose Active Camera in the View menu. Check the framing.
10. Use Flip View to check balance. Then turn it off.
11. You should see: the room, the character, and the camera frame all fit together.
12. Save the file as ~/Art/3D Drawing/024-project-room.blend.

## Check your work
- Are the room parts in one group?
- Does the character fit inside the camera frame?
- Did you save the file?

## Make it yours
Add a second character on another layer. Place it on the other side of the room.

## New words
- **Scene** — everything in one Blender file.
- **Layer group** — a set of layers that act together.
- **Project** — a lesson that joins earlier skills into one file.
