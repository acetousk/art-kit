# 011. Draw on Back and AutoMerge

**You make:** add to 010-pressure.blend (save as 011-back-merge.blend)
**Builds on:** lesson 010
**Time:** 25 min
**Read:** Blender Manual, Draw Mode, Introduction (Drawing Options)

## The idea
Draw on Back puts new strokes under the old strokes in one layer. Quote: "When enabled, new strokes are drawn below all strokes in the layer." AutoMerge joins a new stroke to the end of an old stroke. Use both to clean up line art.

## Look
Open the Draw Mode Tool Settings. Look for Draw on Back and AutoMerge in the Drawing Options.

## Steps
1. Open the file from lesson 010. Stay in Draw Mode.
2. Draw a red line across the page.
3. Open the Drawing Options. Turn on Draw on Back.
4. Draw a blue line that crosses the red line.
5. Check which line is on top.
6. Turn Draw on Back off.
7. Turn on AutoMerge.
8. Draw a line that starts at the end of the red line.
9. You should see: the new line joins the red line at the end.
10. Save the file as ~/Art/3D Drawing/011-back-merge.blend.

## Check your work
- Did the blue line go under the red line with Draw on Back?
- Did AutoMerge join the new line to the old one?
- Did you save the file?

## Make it yours
Draw a leaf. Use Draw on Back for the stem. Draw the leaf on top.

## New words
- **AutoMerge** — join a new stroke to an old one.
- **Draw on Back** — draw new strokes behind old strokes.
- **Option** — a setting you can turn on or off.
