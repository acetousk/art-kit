# 030. Project: Short 2D in 3D Animation

**You make:** ~/Art/3D Drawing/030-project-animation.blend (new file)
**Builds on:** lessons 019–029
**Time:** 60 min
**Read:** Blender Manual, Grease Pencil, Animation (Introduction); Interpolation; Onion Skinning; Camera View

## The idea
Build one short animation in a 3D room. Draw the frames by hand. Use Interpolate for the in-between frames. Use a camera to frame the action. Keep the scene small: 12 frames, few layers.

## Look
Look at the Timeline, the Dope Sheet, and the dashed camera frame.

## Steps
1. Open Blender. File > New > 2D Animation.
2. Draw the room floor and back wall on the Top and Front planes.
3. Add a camera. Set it as the active camera.
4. Add a separate Grease Pencil object for the character. Draw it on frame 1.
5. Draw the character on frame 12 in a new place.
6. Use Interpolate Sequence between frames 1 and 12.
7. Use Onion Skinning to check the frames by eye.
8. Use Auto Keyframe to move the character on the Move gizmo.
9. Play the Timeline from frame 1 to frame 12.
10. You should see: the character moves across the room inside the camera frame.
11. Save the file as ~/Art/3D Drawing/030-project-animation.blend.

## Check your work
- Does the character stay inside the camera frame?
- Does the motion look even?
- Did you save the file?

## Make it yours
Add a second short action. Make the character wave at frame 6. Keep the total under 24 frames.

## New words
- **Animation** — a set of frames that show motion.
- **Key pose** — a main frame of a movement.
- **Project** — a lesson that joins earlier skills into one file.
