# 012. Project: Shapes on Three Planes

**You make:** ~/Art/3D Drawing/012-project-shapes.blend (new file)
**Builds on:** lessons 001–011
**Time:** 50 min
**Read:** Blender Manual, Drawing Plane; Line Tool; Box Tool; Circle Tool; Stroke Placement

## The idea
Use three planes to build one small 3D scene. Quote: "The Drawing Planes selector defines the plane (orientation) to which the new strokes will be restricted." Draw a floor on Top. Draw a wall on Front. Draw a side wall on Side. Each part sits on its own plane.

## Look
Look at the Drawing Plane pop-over. Look at the Toolbar tools: Line, Box, Circle. Look at the Canvas grid.

## Steps
1. Open Blender. Add > Grease Pencil > Blank.
2. Switch to Draw Mode. Turn on Canvas in the Overlays menu.
3. Set Drawing Plane to Top (X-Y).
4. Choose the Box tool. Draw a floor rectangle.
5. Set Drawing Plane to Front (X-Z).
6. Choose the Line tool. Draw the back wall as a line.
7. Choose the Box tool. Draw a door on the back wall.
8. Set Drawing Plane to Side (Y-Z).
9. Choose the Line tool. Draw one side wall.
10. Rotate the view with the navigation gizmo. Check the three parts.
11. You should see: a floor, a back wall, and a side wall.
12. Save the file as ~/Art/3D Drawing/012-project-shapes.blend.

## Check your work
- Does each part sit on the plane you chose?
- Can you see the three parts from a rotated view?
- Did you save the file?

## Make it yours
Add a window to the side wall with the Circle tool. Keep the strokes on the Side plane.

## New words
- **Primitive** — a simple shape such as a box or circle.
- **Plane** — a flat surface where strokes are drawn.
- **Project** — a lesson that joins earlier skills into one file.
