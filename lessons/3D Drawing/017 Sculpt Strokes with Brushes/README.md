# 017. Sculpt Strokes with Brushes

**You make:** add to 016-stroke-menu.blend (save as 017-sculpt.blend)
**Builds on:** lessons 015–016
**Time:** 30 min
**Read:** Blender Manual, Sculpting Brushes; Introduction (Sculpt Mode)

## The idea
Sculpt Mode changes a drawing with a brush. Quote: "an area of the model is altered using a brush." Smooth Stroke removes wobbles. Thickness Stroke makes lines thicker or thinner. The selection mask limits the brush to selected points. Press 1, 2, or 3 to change the mask.

## Look
Look at the Sculpting Brushes list in the Toolbar. Look at the red circle that follows the pen.

## Steps
1. Open the file from lesson 016.
2. Open the Mode menu. Choose Sculpt Mode.
3. Choose the Brush tool in the Toolbar.
4. Choose the Smooth Stroke brush from the brush list.
5. Drag the pen over a wobbly line on the back wall.
6. Choose the Thickness Stroke brush.
7. Drag over a line on the floor. Hold a firm pen touch.
8. Press Ctrl-Z to undo the last drag.
9. You should see: the wobbly line looks smoother after Smooth Stroke.
10. Save the file as ~/Art/3D Drawing/017-sculpt.blend.

## Check your work
- Did Smooth Stroke remove wobbles?
- Did Thickness Stroke change the line width?
- Did you save the file?

## Make it yours
Pick a stroke. Use Smooth Stroke on the top half only. Use the selection mask to limit the brush.

## New words
- **Sculpt** — change a shape by pushing or smoothing it with a brush.
- **Mask** — a set of points that a brush can change.
- **Thickness** — how wide a line is.
