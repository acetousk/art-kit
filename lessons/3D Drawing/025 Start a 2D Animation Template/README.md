# 025. Start a 2D Animation Template

**You make:** ~/Art/3D Drawing/025-2d-template.blend (new file)
**Builds on:** lessons 003, 007
**Time:** 35 min
**Read:** Blender Manual, Grease Pencil, Introduction (2D Animation Template); Animation (Introduction)

## The idea
The 2D Animation template sets up Grease Pencil for you. Quote: "The animation timeline will automatically create a new keyframe when Grease Pencil is used on empty frames." Each drawing goes on its own frame. Blender makes a keyframe for each new frame you draw on.

## Look
Look at the Timeline at the bottom. Each diamond shape is a keyframe. The current frame has a marker.

## Steps
1. Open Blender.
2. Open File > New > 2D Animation.
3. Look at the template. The viewport is set up for 2D drawing.
4. Click frame 1 in the Timeline.
5. Draw a small ball in Draw Mode.
6. Click frame 2 in the Timeline.
7. Draw the ball a little to the right.
8. Click frame 3. Draw the ball a little further right.
9. You should see: three keyframes in the Timeline, one for each drawn frame.
10. Save the file as ~/Art/3D Drawing/025-2d-template.blend.

## Check your work
- Does each drawn frame have a keyframe?
- Does the ball move a little on each frame?
- Did you save the file?

## Make it yours
Draw a bouncing ball for ten frames. Move the ball up, then down.

## New words
- **Frame** — one still picture in a sequence.
- **Timeline** — the bar that shows frames.
- **Template** — a file setup you can start from.
