# 018. Project: Clean Up and Fill a Drawing

**You make:** ~/Art/3D Drawing/018-project-cleanup.blend (new file)
**Builds on:** lessons 009–017
**Time:** 50 min
**Read:** Blender Manual, Fill Tool; Stroke Menu; Sculpting Brushes; Erase Tool

## The idea
Clean line art before you color it. Quote: "Edit Lines: Use only fill guide strokes." Use Edit Mode to fix points. Use Sculpt Mode to smooth lines. Use the Fill tool last. Clean lines give clean fills.

## Look
Look at the Fill tool Boundary option. Look at the Stroke menu. Look at the Sculpt brush list.

## Steps
1. Open Blender. Add > Grease Pencil > Blank.
2. Draw a simple cup shape with five strokes. Use Draw Mode.
3. Erase extra lines with the Erase brush.
4. Open Edit Mode. Choose the Strokes select mode.
5. Select the wobbly strokes. Open the Stroke menu. Choose Simplify.
6. Open Sculpt Mode. Choose Smooth Stroke. Smooth the sides of the cup.
7. Open Draw Mode. Choose the Fill tool.
8. Add a material with a fill color.
9. Click inside the cup. The cup fills.
10. You should see: a clean cup with one solid fill.
11. Save the file as ~/Art/3D Drawing/018-project-cleanup.blend.

## Check your work
- Are the lines smooth after Sculpt Mode?
- Does the fill stay inside the cup?
- Did you save the file?

## Make it yours
Draw a fish. Clean the lines. Fill the body and the tail in two colors.

## New words
- **Clean-up** — fix lines before coloring.
- **Fill guide** — a stroke that tells Fill where to stop.
- **Project** — a lesson that joins earlier skills into one file.
