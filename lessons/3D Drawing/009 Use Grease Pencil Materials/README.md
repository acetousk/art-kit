# 009. Use Grease Pencil Materials

**You make:** add to 008-hide-lock.blend (save as 009-materials.blend)
**Builds on:** lesson 008
**Time:** 30 min
**Read:** Blender Manual, Grease Pencil Materials

## The idea
A material sets the color of a stroke and its fill. Quote: "Each stroke can have a stroke (outline) component, a fill component, or both." Each stroke uses one material. There is always one active material. New strokes use the active material. Change a material and all strokes that use it change too.

## Look
Open the Material Properties tab. Look at the Material Slots list. Look at the Stroke and Fill panels inside the material.

## Steps
1. Open the file from lesson 008.
2. Open the Material Properties tab.
3. Click the plus button in the Material Slots list. A new slot appears.
4. Click New next to the material name. Rename it Ink.
5. Open the Stroke panel. Set the color to dark brown.
6. Open the Fill panel. Turn on Fill.
7. Set the fill color to light yellow.
8. Go to Draw Mode. Draw a closed circle with the Ink material.
9. You should see: the stroke is brown. The inside is yellow.
10. Save the file as ~/Art/3D Drawing/009-materials.blend.

## Check your work
- Does the material have Stroke and Fill parts?
- Did the new circle use the active material?
- Did you save the file?

## Make it yours
Make a second material called Sky. Set its fill to light blue. Draw a shape with it.

## New words
- **Material** — the color and style of a stroke.
- **Fill** — the color inside a closed stroke.
- **Slot** — a place in the list where a material sits.
