# 004. Save and Undo in Blender

**You make:** ~/Art/3D Drawing/004-save-test.blend
**Builds on:** lesson 003
**Time:** 20 min
**Read:** Blender Manual, Undo & Redo; Topbar (File Menu)

## The idea
Undo goes back one action. Save As puts a copy of your work in a new file name. Quote: "If you want to undo your last action, just press Ctrl-Z." Blender saves only the file you choose. Save often.

## Look
Look at the File menu in the top bar. Look at Edit > Undo in the same bar.

## Steps
1. Open the file from lesson 003.
2. Draw one extra stroke in Draw Mode.
3. Press Ctrl-Z. The extra stroke goes away.
4. Press Shift-Ctrl-Z. The stroke comes back.
5. Open File > Save As.
6. Type 004-save-test.blend as the file name.
7. Open the folder ~/Art/3D Drawing.
8. Click Save.
9. You should see: the title shows the new file name.
10. Press Ctrl-S. Blender saves the file again with no new name.

## Check your work
- Did Ctrl-Z remove the extra stroke?
- Is the file in ~/Art/3D Drawing?
- Did Ctrl-S save the file?

## Make it yours
Make three strokes. Press Ctrl-Z three times. Count how many strokes return.

## New words
- **Undo** — go back one action.
- **Redo** — go forward again after undo.
- **Save As** — save the file with a new name or place.
