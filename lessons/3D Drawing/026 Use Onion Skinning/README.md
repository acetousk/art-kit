# 026. Use Onion Skinning

**You make:** add to 025-2d-template.blend (save as 026-onion.blend)
**Builds on:** lesson 025
**Time:** 30 min
**Read:** Blender Manual, Onion Skinning

## The idea
Onion skinning shows ghosts of nearby frames. Quote: "Onion Skinning shows ghosts of the keyframes before and after the current frame." The ghosts help you draw the next frame. Set how many keyframes show before and after. Set the opacity of the ghosts.

## Look
Look at the Onion Skinning panel in the Object Data tab. Look at the onion icon in the Overlays menu.

## Steps
1. Open the file from lesson 025.
2. Open the Overlays menu in the header.
3. Turn on Onion Skinning under Grease Pencil.
4. Go to frame 3 in the Timeline.
5. Look at the faint ghosts of frames 2 and 4.
6. Open the Object Data tab. Find the Onion Skinning panel.
7. Set Keyframes Before to 1. Set Keyframes After to 1.
8. Lower the Opacity a little.
9. Draw the ball on frame 3 using the ghosts as a guide.
10. You should see: the ghost of frame 2 and frame 4 near the ball.
11. Save the file as ~/Art/3D Drawing/026-onion.blend.

## Check your work
- Can you see ghosts of the nearby frames?
- Did you change the number of ghosts?
- Did you save the file?

## Make it yours
Set Keyframes Before to 3. Draw a walk cycle of four frames. Use the ghosts to keep steps even.

## New words
- **Onion skin** — a faint view of nearby frames.
- **Ghost** — a faint copy of a frame.
- **Opacity** — how solid or faint an item looks.
