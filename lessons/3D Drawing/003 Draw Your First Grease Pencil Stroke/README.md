# 003. Draw Your First Grease Pencil Stroke

**You make:** ~/Art/3D Drawing/003-first-stroke.blend
**Builds on:** lessons 001–002
**Time:** 30 min
**Read:** Blender Manual, Grease Pencil, Introduction (Quick Start); Draw Mode, Introduction

## The idea
Grease Pencil is a Blender object. It holds strokes that you draw in 3D space. Strokes go in Draw Mode. A Grease Pencil object needs a keyframe before you draw. Quote: "Click and drag across the viewport to add strokes to the Grease Pencil object." (Quick Start.)

## Look
Look at the Mode menu in the 3D Viewport header. Look at the Toolbar on the left. In Draw Mode, the Toolbar shows drawing tools. A colored circle follows the pen.

## Steps
1. In Blender, in Object Mode, open Add > Grease Pencil > Blank.
2. In the Timeline header, click the record button. This turns on Auto Key.
3. Open the Mode menu in the 3D Viewport header.
4. Choose Draw Mode.
5. In the Toolbar, choose the Brush tool.
6. In the Tool Settings, check the active brush and material.
7. Hold the pen on the viewport. Click and drag to draw a line.
8. Draw a simple house with three strokes.
9. You should see: the strokes stay on the screen. The Timeline shows a keyframe at frame 1.
10. Open File > Save As. Save the file as ~/Art/3D Drawing/003-first-stroke.blend.

## Check your work
- Is the new object a Grease Pencil object?
- Does the Timeline show a keyframe after you drew?
- Did the strokes follow the pen?

## Make it yours
Draw a leaf on a new frame. Move to the next frame in the Timeline first. Then draw the leaf.

## New words
- **Keyframe** — a frame that stores the state of an object at one time.
- **Stroke** — one line drawn with Grease Pencil.
- **Draw Mode** — the mode where new strokes are made.
