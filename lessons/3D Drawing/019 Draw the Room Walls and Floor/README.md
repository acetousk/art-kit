# 019. Draw the Room Walls and Floor

**You make:** ~/Art/3D Drawing/019-room.blend (new file)
**Builds on:** lessons 005, 006, 012
**Time:** 40 min
**Read:** Blender Manual, Stroke Placement; Drawing Plane; 3D Cursor

## The idea
A room is three flat parts: floor, back wall, and side wall. Draw each part on its own plane. Quote: "Strokes are drawn on the plane determined by the XZ axes (front view)." Use the same method as lesson 012. Keep the room small. Use few strokes.

## Look
Look at the room on the Canvas grid. Check that the floor is flat. Check that the walls stand up.

## Steps
1. Open Blender. Add > Grease Pencil > Blank.
2. Turn on Canvas in the Overlays menu.
3. Open Draw Mode. Set Drawing Plane to Top (X-Y).
4. Draw a floor rectangle with the Box tool.
5. Set Drawing Plane to Front (X-Z).
6. Draw the back wall with the Box tool. It stands on the floor edge.
7. Set Drawing Plane to Side (Y-Z).
8. Draw one side wall with the Box tool.
9. Use the navigation gizmo. Turn the view. Check that the parts meet.
10. You should see: a floor with two walls that meet at the corners.
11. Save the file as ~/Art/3D Drawing/019-room.blend.

## Check your work
- Does the floor lie flat on the grid?
- Do the walls meet the floor edge?
- Did you save the file?

## Make it yours
Add a window to the back wall. Use the Circle tool. Keep it on the Front plane.

## New words
- **Floor** — the flat bottom of a room.
- **Wall** — a vertical flat part of a room.
- **Corner** — the place where two walls meet.
