# 015. Select Points, Strokes, and Segments

**You make:** add to 014-erase.blend (save as 015-select.blend)
**Builds on:** lesson 014
**Time:** 30 min
**Read:** Blender Manual, Introduction (Edit Mode); Selecting Grease Pencil Elements

## The idea
Edit Mode changes single points and whole strokes. Quote: "Points: To select individual points." There are three select modes. Points picks one point. Strokes picks a full stroke. Segments picks the points between two strokes. Press 1, 2, or 3 to change the mode.

## Look
Look at the Select Mode buttons in the 3D Viewport header. There are three buttons: Points, Strokes, Segments.

## Steps
1. Open the file from lesson 014.
2. Open the Mode menu. Choose Edit Mode.
3. Look at the three Select Mode buttons in the header.
4. Click the Points button.
5. Click one point on the room wall. It turns selected.
6. Click the Strokes button.
7. Click one line on the floor. The whole stroke is selected.
8. Click the Segments button.
9. Click between two lines where they cross. Read which points are picked.
10. You should see: the selected items change color when you change the mode.
11. Save the file as ~/Art/3D Drawing/015-select.blend.

## Check your work
- Did Points select one point at a time?
- Did Strokes select a full line?
- Did you save the file?

## Make it yours
Select all strokes on the back wall in Strokes mode. Move to the next mode and note the change.

## New words
- **Point** — one dot on a stroke.
- **Segment** — the part of a stroke between two other strokes.
- **Select** — mark an item so an action changes only that item.
