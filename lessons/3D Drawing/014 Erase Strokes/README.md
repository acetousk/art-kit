# 014. Erase Strokes

**You make:** add to 013-fill.blend (save as 014-erase.blend)
**Builds on:** lesson 013
**Time:** 25 min
**Read:** Blender Manual, Erase Tool; Brush Tool

## The idea
The Erase tool removes strokes you already drew. Quote: "The Erase tool erases already drawn strokes." The Erase brush uses the same brush tool. Ctrl with the pen switches to the eraser for a quick fix. Erase the mistake, not the whole drawing.

## Look
Look at the Brush tool settings. Look for the Size value and the Default Eraser Brush option.

## Steps
1. Open the file from lesson 013. Stay in Draw Mode.
2. Choose the Brush tool in the Toolbar.
3. In the Tool Settings, find the Eraser brush.
4. Choose an Erase brush from the brush list.
5. Set Size to a small value.
6. Drag over one stroke on the back wall. The stroke disappears.
7. Press Ctrl-Z. The stroke comes back.
8. Hold Ctrl and drag with the pen. The eraser works for one drag.
9. You should see: the stroke you dragged over is removed.
10. Save the file as ~/Art/3D Drawing/014-erase.blend.

## Check your work
- Did the Erase brush remove only the stroke you crossed?
- Did Ctrl-Z bring the stroke back?
- Did you save the file?

## Make it yours
Draw a cat face with lines. Erase the extra lines. Keep only the outline.

## New words
- **Erase** — remove strokes.
- **Size** — how wide a brush is.
- **Eraser brush** — a brush that removes strokes.
