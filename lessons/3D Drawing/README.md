# 3D Drawing with Blender

Blender 5.3 (Flathub). Grease Pencil, version 3. Steps come from the Blender 5.3 Manual.

- Files: ~/Art/3D Drawing/<name>.blend
- Keep scenes small. The device has 4 GB RAM.
- No add-ons. No downloads. No internet.
- Lessons: 30. Projects: 012, 018, 024, 030. See INDEX.md.
