# 008. Hide and Lock Layers

**You make:** add to ~/Art/3D Drawing/007-layers.blend (save as 008-hide-lock.blend)
**Builds on:** lesson 007
**Time:** 25 min
**Read:** Blender Manual, Layers (Layer Tree); Viewport Overlays (Grease Pencil)

## The idea
Hide and Lock keep one layer safe while you work on another. Quote: "Toggle layer from being editable." Hide removes a layer from the viewport and the render. Lock stops changes to it. Autolock Inactive Layer locks every layer except the active one.

## Look
Look at the icons next to each layer name in the Layers list. The eye icon hides a layer. The lock icon locks it.

## Steps
1. Open the file from lesson 007.
2. Click the eye icon next to Walls. The Walls strokes disappear.
3. Click the eye icon again. The strokes come back.
4. Click the lock icon next to Walls.
5. Try to draw on Walls. Nothing changes.
6. Click the lock icon again to unlock Walls.
7. Open the Layer Specials menu. Choose Autolock Inactive Layer.
8. Click the other layer. Draw a line on it.
9. You should see: only the active layer can change.
10. Save the file as ~/Art/3D Drawing/008-hide-lock.blend.

## Check your work
- Does a hidden layer disappear from the viewport?
- Does a locked layer stay the same when you draw?
- Did you save the file?

## Make it yours
Hide all layers except one. Use Hide Others from the Layer Specials menu.

## New words
- **Hide** — turn off a layer's visibility.
- **Lock** — stop a layer from being edited.
- **Autolock** — lock all inactive layers at once.
