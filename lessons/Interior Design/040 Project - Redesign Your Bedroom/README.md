# 040. Project - Redesign Your Bedroom

**You make:** ~/Art/Interior Design/My-Bedroom/Bedroom-Before-After.kra  (and save My-Bedroom.sh3d)
**Builds on:** lessons 001 to 039
**Time:** 50–60 min
**Read:** Parsons, Interior Decoration, PDF pages 357–358; Wharton and Codman, The Decoration of Houses, PDF page 336

## The idea
Parsons says function or fitness is the fundamental idea of a room. Every object must do its own work in the best way. Wharton adds that beauty depends on fitness. Now use every idea from the course on your own bedroom. First photograph it as it is. Then change five things, and photograph it again.
"Function or fitness is the fundamental idea of the room." (Parsons, PDF page 357)

## Look
- Parsons PDF page 358, top: find "every object in it is so placed that it does its own work."
- Wharton PDF page 336, bottom: find the line that says beauty depends on fitness.

## Steps
1. Open My-Bedroom.sh3d. Choose 3D view > Virtual visit. Stand at the door.
2. Click Create photo… Make a fast-quality PNG. Save it as Bedroom-Before.png in the My-Bedroom folder.
3. Ask eight questions: function, scale, proportion, balance, focal point, movement, color and light, clearances. Label each answer.
4. Pick the five weakest answers.
5. Make five changes, one at a time. Ideas: move the bed, resize a piece, add a lamp, clear a path.
6. After each change, look at the 3D view. Keep the change only if it helps.
7. Run your tests again: bed pads, 60 in turning pad, door pads, and 36 in paths.
8. Stand at the same door point. Make Bedroom-After.png the same way.
9. Open Krita. Choose File > New. Set 3200 px by 1800 px. Name it Bedroom-Before-After.
10. Open each PNG. Copy and paste them side by side. Size them to match.
11. Use the Text tool. Label BEFORE and AFTER. List the five changes in short lines.
12. Choose File > Save As… Save as Bedroom-Before-After.kra in the My-Bedroom folder.
13. Click the Save home button in Sweet Home 3D.

You should see: two photos side by side, five changes listed, all tests passed.

## Check your work
1. Does the after photo show a clear improvement?
2. Does each change have a reason from a lesson?
3. Do all clearance tests still pass?

## Make it yours
- Ask someone to guess which five things you changed.
- Pick one change that you tried and rejected. Write why.

## New words
- **fitness** — how well something suits its use.
- **before and after** — two views that show a change.
- **audit** — a check of a design against a list of rules.
