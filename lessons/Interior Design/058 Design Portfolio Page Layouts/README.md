# 058. Design Portfolio Page Layouts

**You make:** ~/Art/Interior Design/Portfolio/Portfolio-Page-Template.kra  (new file)
**Builds on:** lesson 057
**Time:** 35–45 min
**Read:** Parsons, Interior Decoration, PDF pages 106–107; Krita Manual, Grids and Guides Docker and Snapping

## The idea
Every page of your portfolio should look like it belongs with the others. The same margins, the same title place, the same type size. A template does this. Parsons writes about furniture, but the idea is the same for a page: one thing must dominate, and the rest must line up with it. Lines that run the same way give a sense of order. Make a template with a grid, then reuse it.
"One must dominate." (Parsons, PDF page 106)

## Look
- PDF page 106, top: find the rule that rugs and furniture follow the lines of the room.
- PDF page 106, bottom: find the warning about furniture at random angles.

## Steps
1. Open Krita. Choose File > New. Set 3000 px by 2000 px. Name it Portfolio-Page-Template.
2. Open the Grids and Guides docker. Turn on Show Grid. Turn on Snap to Grid.
3. Set the X spacing and Y spacing so the page splits into a clear grid.
4. Choose View > Show Rulers. Drag guides out of the rulers to mark margins. Show Guides if hidden.
5. Use the Rectangle tool to draw a big photo box. It must be the biggest thing: it dominates.
6. Draw a smaller box for a second picture. Draw a text box area under them.
7. Use the Text tool. Place Title, Skill, and Caption in the template.
8. Check that every box snaps to the grid.
9. Make a second layout for a plan page: plan on the left, notes on the right.
10. Make a third layout for a before and after page: two equal boxes.
11. Save this file as Portfolio-Page-Template.kra in the Portfolio folder. Reopen it for each new page.
12. Save your changes.

You should see: one page with a grid, three layouts, and a saved template.

## Check your work
1. Does one box dominate the page?
2. Do all boxes snap to the grid?
3. Do the margins match on every layout?

## Make it yours
- Design a layout for a four-photo page. Which photo dominates?
- Turn off the grid. Does the page still look in order?

## New words
- **template** — a saved page layout you can reuse.
- **guide** — a line you drag out to help you align things.
- **margin** — the empty border around the edge of a page.
