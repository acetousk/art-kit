# 020. Hue, Value, and Intensity

**You make:** ~/Art/Interior Design/My-Bedroom/Bedroom-Color-Chart.kra  (new file)
**Builds on:** lesson 018
**Time:** 30–45 min
**Read:** Vanderpoel, Color Problems, PDF pages 48–50, 53, 55, and 59

## The idea
Every color has three qualities. Vanderpoel names them hue, purity, and luminosity. Hue is the family name, such as red or blue. Purity is how free the color is of white, black, or other colors. Luminosity is brightness, and designers also say value for light and dark, and intensity for purity. Yellow is the lightest hue, violet is cold and retiring, and red is warm and advancing.
"a room papered or painted in yellow will give you the lightest room" (Vanderpoel, PDF page 50)

## Look
- PDF page 49, top: find the three qualities named in order: hue, purity, luminosity.
- PDF page 50, top: find how a bright color can lighten a dark part of a room.
- PDF page 53, middle: find violet as a "retiring color" that serves as a background.
- PDF page 55, top: find that a pure blue room looks larger, but empty and cold.
- PDF page 59, top: find "Red is a warm color and an advancing one."

## Steps
1. Open Krita. Choose File > New. Set 2000 px by 1500 px. Name it Bedroom-Color-Chart.
2. Open Settings > Dockers > Advanced Color Selector.
3. Choose the Rectangle tool. Set Fill to Foreground color. Set Outline to No Outline.
4. In the top row, make six squares. Fill them with violet, blue, green, yellow, orange, red. These are hues.
5. Under each square, make five more squares. Pick the same hue but lighter each time. These are tints.
6. Under those, make five squares of the same hue but darker each time. These are shades.
7. Make a row with one hue at full purity, then five squares mixed with gray. These are broken tints.
8. Use the Text tool. Label the rows: Hue, Value (light to dark), Intensity (pure to gray).
9. Open the Palette docker. Click an empty slot to add your color. Add six colors you may use.
10. Choose File > Save As… Save as Bedroom-Color-Chart.kra in the My-Bedroom folder.

You should see: a chart with hue across, value down, and gray steps.

## Check your work
1. Can you point to the lightest hue?
2. Can you tell value from intensity?
3. Does your chart have a row of gray-mixed colors?

## Make it yours
- Take your bedroom and mark which hue family each major object belongs to.
- Find the most pure color in your room. What is it?

## New words
- **hue** — the family name of a color: red, blue, yellow.
- **value** — how light or dark a color is.
- **intensity** — how pure or gray a color is.
