# 060. Project - Final Portfolio

**You make:** ~/Art/Interior Design/Portfolio/Portfolio-Final/Page-01.png to Page-08.png  (pages in order)
**Builds on:** lessons 057 to 059
**Time:** 50–60 min
**Read:** Parsons, Interior Decoration, PDF page 320; Wharton and Codman, The Decoration of Houses, PDF page 338

## The idea
Now build the portfolio. Page 1 is the cover. Page 2 is the statement. Pages 3 to 8 are your best six pieces. Parsons says no one owns good taste, and taste grows with study. Your portfolio shows where you are now.
"no man has by divine right a monopoly of good taste" (Parsons, PDF page 320)

## Look
- Parsons PDF page 320, bottom: find the lines that say taste improves with study.
- Wharton PDF page 338, top: find "Moderation, fitness, relevance."

## Steps
1. Open Portfolio-Selection.kra. Look at your six to eight chosen pieces.
2. Open Portfolio-Page-Template.kra. Choose File > Save As… for each page, named Page-03, Page-04, and so on.
3. For each page, paste in the picture. Pick a layout: photo page, plan page, or before and after.
4. Write the title of the piece at the top.
5. Write one line: the problem, and one line: what you did.
6. Write one line: which course idea it shows.
7. Check that the biggest picture dominates the page.
8. For plan pages, show the numbers. For the client page, show the board.
9. Open Portfolio-Cover-and-Statement.kra and Design-Statement.kra. These are Pages 1 and 2.
10. Check every page for the same margins, the same fonts, and the same title place.
11. Cut any page that repeats an idea.
12. Choose File > Export… for each page. Save as Page-01.png, Page-02.png, and so on, in a folder named Portfolio-Final.
13. Open the PNG files in order. Read them as a stranger would.

You should see: a folder of eight page images, in order, with one look.

## Check your work
1. Does every page use the same template?
2. Does each page name the idea it shows?
3. Is every picture sharp and large enough?

## Make it yours
- Show the portfolio to a friend. Ask which page they remember.
- Choose one page to improve each month. Add new work in a new page.

## New words
- **monopoly** — sole ownership of something. No one owns good taste.
- **order** — the sequence of pages in a portfolio.
- **sharp** — clear, with no blur.
