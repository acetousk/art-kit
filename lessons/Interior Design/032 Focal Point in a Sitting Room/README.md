# 032. Focal Point in a Sitting Room

**You make:** add to ~/Art/Interior Design/Room-Studies/Room-Studies.sh3d
**Builds on:** lesson 031
**Time:** 35–45 min
**Read:** Wharton and Codman, The Decoration of Houses, PDF page 140; Parsons, Interior Decoration, PDF pages 140, 143, and 153

## The idea
A focal point is the place the eye goes first. Wharton says the fireplace was long the chief feature of a room, and the room was planned around it. Parsons says color pulls the eye more than any other force. So a strong color in a small area makes a focal point. Everything else should be quieter, and your seats should face it.
"The fireplace was formerly always regarded as the chief feature of the room" (Wharton and Codman, PDF page 140)

## Look
- Wharton PDF page 140: find how a small mantel can be as architectural as a great one.
- Parsons PDF page 140, top: find "colour is the most attractive of all forces to the eye."
- Parsons PDF page 153: find how the figures in a picture look at the main one.

## Steps
1. Open Room-Studies.sh3d. Click Create walls.
2. Start 3 ft right of the study. Draw a sitting room 14 ft by 16 ft inside.
3. Add a door and a window. Click Create rooms, double-click inside, and name it Sitting Room.
4. Pick the focal point. Look in the catalog for a fireplace. If there is none, use a tall bookcase.
5. Place it in the middle of one wall. Give it the strongest color in the room.
6. Set the walls and floor to quiet colors, so the focal point leads.
7. Place two armchairs and a sofa. Turn each to face the focal point.
8. Keep the window off the focal wall. A bright window pulls the eye away.
9. Add a rug parallel to the focal wall.
10. Add a text label: Focal point — what I chose and why.
11. Test a 60 in by 60 in turning pad. Test a 36 in path to each seat.
12. Click the Save home button.

You should see: all seats pointing to one strong feature.

## Check your work
1. Can you find the focal point in two seconds?
2. Do all seats face it?
3. Is every other color quieter?

## Make it yours
- Add a second strong thing, like a bright chair. Does it fight the focal point?
- Move the focal point to the window wall. What changes?

## New words
- **focal point** — the main thing that the eye sees first.
- **emphasis** — extra strength given to one part of a design.
- **mantel** — the shelf above a fireplace.
