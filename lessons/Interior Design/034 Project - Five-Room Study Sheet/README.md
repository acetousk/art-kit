# 034. Project - Five-Room Study Sheet

**You make:** ~/Art/Interior Design/Room-Studies/Five-Room-Study-Sheet.kra  (and a PNG export)
**Builds on:** lessons 029 to 033
**Time:** 45–60 min
**Read:** Wharton and Codman, The Decoration of Houses, PDF pages 337–338; Krita Manual, Transform Tool

## The idea
You have five rooms and five ideas: scale, proportion, balance, focal point, and movement. A study sheet puts them on one page. Wharton ends her book with this: the best quality is simplicity. Moderation, fitness, relevance. Each room on your sheet should show one idea clearly, with everything else left out.
"The supreme excellence is simplicity." (Wharton and Codman, PDF page 338)

## Look
- PDF page 337, bottom: find the line comparing proportion to anatomy in sculpture.
- PDF page 338, top: find the words "Moderation, fitness, relevance."

## Steps
1. Open Room-Studies.sh3d. Choose 3D view > Virtual visit.
2. For each room, stand in the door. Choose a view that shows the idea.
3. Click Create photo… Make a fast-quality PNG. Save it as Photo-Living.png in the Room-Studies folder.
4. Do the same for the dining room, study, sitting room, and hall. Name each photo with the room name.
5. Open Krita. Choose File > New. Set 3000 px by 2000 px. Name it Five-Room-Study-Sheet.
6. Open each photo with File > Open… Copy it. Paste it into the sheet. Size it with the Transform tool.
7. Arrange the five photos in a neat grid. Leave a margin around each.
8. Use the Text tool under each photo. Write the room name, the idea, and how the room shows it.
9. Add a title: Five Rooms, Five Ideas. Add your name.
10. Look at the whole sheet. Cut anything that does not help. Keep the sheet simple.
11. Choose File > Save As… Save as Five-Room-Study-Sheet.kra in the Room-Studies folder.
12. Choose File > Export… Save a PNG of the same name.

You should see: a sheet with five photos, five captions, and a title.

## Check your work
1. Does each caption name one idea?
2. Are the photos the same size?
3. Is there empty space around each picture?

## Make it yours
- Pick the best room of the five. Redo its photo at the best quality level.
- Write one rule you learned that you did not know before.

## New words
- **study sheet** — one page that shows what you learned.
- **grid** — rows and columns of equal spaces.
- **caption** — a short text under a picture.
