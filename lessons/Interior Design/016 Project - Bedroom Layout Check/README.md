# 016. Project - Bedroom Layout Check

**You make:** ~/Art/Interior Design/My-Bedroom/Bedroom-Layout-Check.pdf  (and save My-Bedroom.sh3d)
**Builds on:** lessons 009 to 015
**Time:** 45–60 min
**Read:** Wood and Burbank, The Art of Interior Decoration, PDF pages 331–332; ADA 2010 Standards, PDF page 111

## The idea
A good room has order and space. Wood and Burbank say you should not crowd walls or tables. Rest comes from order and open space. You now have the tools to test that. This project gathers all your tests in one plan: sized furniture, clear floor beside the bed, a turning space, door clearances, and 36 in paths. You will fix what fails, then print a check sheet.
"one must produce the quality of restfulness by order and space" (Wood and Burbank, PDF page 331)

## Look
- PDF page 331, near the middle: find the rule about crowding.
- PDF page 332, top: find the rule about figured (patterned) surfaces. You will use it in lesson 19.

## Steps
1. Open My-Bedroom.sh3d. Make sure every real piece is in the plan at its real size.
2. List the tests: bed sides (30 by 48), turning space (60 by 60), door pads, three 36 in paths, switch.
3. Check each test one at a time. Mark a text label PASS or FIX next to it.
4. For each FIX, move one piece of furniture. Test again.
5. Do not remove a piece unless nothing else works. Write the reason in a text label.
6. When every test says PASS, add a title text: Bedroom Layout Check.
7. Add one text with three lines: what you moved, what you removed, what you learned.
8. Choose File > Page setup… Pick a scale where all pads and numbers are readable.
9. Choose File > Print preview… Check the page.
10. Choose File > Print to PDF… Save as Bedroom-Layout-Check.pdf in the My-Bedroom folder.
11. Open Furniture > Modify… for each test pad. Turn off its visibility. The plan returns to clean.
12. Click the Save home button.

You should see: a PDF full of PASS labels, and a clean plan without red pads.

## Check your work
1. Does every test say PASS?
2. Did you write what you changed?
3. Did you keep the test pads in the PDF but hide them in the plan?

## Make it yours
- Ask a family member to walk the room with their eyes closed. Where do they bump?
- Compare your layout with the room before you started. Which is calmer?

## New words
- **layout** — the placement of furniture in a room.
- **restfulness** — a feeling of calm and ease in a room.
- **visibility** — whether a piece is shown in the plan and 3D view.
