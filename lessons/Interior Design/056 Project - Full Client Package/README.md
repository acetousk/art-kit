# 056. Project - Full Client Package

**You make:** ~/Art/Interior Design/Client-Project/Client-Plan.pdf  (and final Client-Presentation.kra and PNG)
**Builds on:** lessons 049 to 055
**Time:** 50–60 min
**Read:** de Wolfe, The House in Good Taste, PDF page 33; Parsons, Interior Decoration, PDF page 358

## The idea
The package is what you give the client: a plan in PDF, photos, a mood board, and a presentation board. Before you give it, check it against the brief. de Wolfe says taste can be learned. We must learn to see suitability, simplicity, and proportion, and then apply what we know to our needs. Parsons says the test is whether each object does its own work. Run that test now, and fix what fails.
"We must learn to recognize suitability, simplicity and proportion, and apply our knowledge to our needs." (de Wolfe, PDF page 33)

## Look
- de Wolfe PDF page 33, bottom: find the three qualities, and the tiny room with a huge chair.
- Parsons PDF page 358, top: find "every object in it is so placed that it does its own work."

## Steps
1. Open Client-Brief.kra. Read the success test.
2. Open Client-Project.sh3d. Check each success test sentence against the plan. Write PASS or FIX.
3. For each FIX, change the plan. Test it again.
4. Check scale, proportion, balance, focal point, and light. Write one line for each.
5. Check clearances: 60 in turning space, 36 in paths, 32 in door, 30 in by 48 in seat space.
6. Hide the test pads: Furniture > Modify…, turn off visibility.
7. Add dimension lines and room labels. Add a title and your name.
8. Choose File > Page setup… Choose File > Print preview… Choose File > Print to PDF… Save as Client-Plan.pdf.
9. Make new photos if the plan changed. Replace the old ones.
10. Open Client-Presentation.kra. Replace any old picture. Fix the captions.
11. Choose File > Save As… Save as Client-Presentation.kra. Choose File > Export… Save a PNG.
12. Check the Client-Project folder. It must hold the brief, plan PDF, four photos, two boards, and the presentation.

You should see: a folder with every item, and all PASS marks.

## Check your work
1. Does every success test say PASS?
2. Is every file in the folder, with a clear name?
3. Would the client understand the board without you there?

## Make it yours
- Write a short note to the client: three lines on why you made each choice.
- Ask a person to find one problem. Fix it.

## New words
- **package** — all the files you give to a client.
- **suitability** — how well a thing fits its use and its place.
- **success test** — the list of checks that show the design works.
