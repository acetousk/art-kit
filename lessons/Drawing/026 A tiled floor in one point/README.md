# 026. A tiled floor in one point

**You make:** ~/Art/Drawing/026-tiled-floor.kra  
**Builds on:** lesson 025  
**Time:** 45 min  
**Read:** Perspective for Artists (Vicat Cole), PDF page 198; Freehand Perspective and Sketching (Norton), PDF pages 144–145

## The idea
A tiled floor is many equal squares. Mark equal steps along the front. Draw lines to the main point. Draw the first tile with extra care. One diagonal through all the lines shows where each row ends. "much depends on the correctness of this first rectangle" (Norton, PDF 144)

## Look
Vicat Cole PDF 198, Figs. 326 and 327: a floor of chequer tiles. Norton PDF 144–145, Figs. 198 and 200: a tiled floor and the end view of a step.

## Steps
1. Open Krita. Make a new document, 4000 by 2400 px. Add a horizon guide.
2. Mark the main point P on the horizon. Draw a base line at the bottom.
3. Mark eight equal steps along the base line. Use dots.
4. Draw a line from each dot to P.
5. Draw the first square at the front. Draw its diagonal.
6. Extend that diagonal. Find where it crosses each line to P.
7. At each crossing, draw a horizontal line across the floor.
   You should see: A grid of tiles. Each row is shallower than the last.
8. Pick the Fill Tool. Set the foreground color to dark gray.
9. Fill every other tile to make a checker pattern.
10. Add a wall at the back with a door or window.
11. Press Ctrl + Shift + S. Save as ~/Art/Drawing/026-tiled-floor.kra.

## Check your work
- Are the tiles at the front the deepest?
- Do all horizontal lines stay level?
- Does the checker pattern look flat on the ground?

## Make it yours
- Draw a floor of long planks.
- Draw a chessboard from one corner.

## New words
- **tile** — one flat square in a floor pattern.
- **chequer** — a pattern of alternate light and dark squares.
- **grid** — a net of lines that cross.
