# 025. Find the depth of a square

**You make:** ~/Art/Drawing/025-square-depth.kra  
**Builds on:** lesson 024  
**Time:** 40 min  
**Read:** Perspective for Artists (Vicat Cole), PDF pages 28, 48–51

## The idea
The depth of a flat square is hard to guess. Pick it by eye for one square. Draw its diagonal and extend it to the horizon. That point is the vanishing point of the diagonals. A second square made with that point must have the same depth as the first. This is a good test. "It is of supreme importance in every picture that the depth of some foreshortened space should be drawn with absolute accuracy." (Vicat Cole, PDF 48)

## Look
PDF 50, Fig. 82: a bird's-eye view of the painter and the picture. PDF 51, Fig. 83: the diagonal point is as far from the main point as the painter is from the picture.

## Steps
1. Open Krita. Make a new document, 4000 by 2400 px. Add a horizon guide in the middle.
2. Draw a long horizontal line near the bottom. This is the base line.
3. Mark a point P on the horizon, in the middle. This is the main vanishing point.
4. On the base line, mark points A, B, C, and E. Make AB, BC, and CE all the same length.
5. Draw a line from each of A, B, C, and E to P.
6. Draw a horizontal line from line A–P to line B–P. Place it by eye to make a square.
7. Draw a diagonal from A to the far-right corner of that square. Extend it to the horizon.
8. Mark that point D. Zoom out with the minus key if D is off the canvas.
9. Draw a line from C to D. Mark where it crosses line E–P.
10. Draw a horizontal line through that crossing, from line C–P to line E–P.
   You should see: A second square. Its back edge is on the same level as the first back edge.
11. Use the Measure Tool to check that both back edges are at the same height.
12. Press Ctrl + Shift + S. Save as ~/Art/Drawing/025-square-depth.kra.

## Check your work
- Does the first shape look like a square on the ground?
- Are the two back edges at the same height?
- Did you extend the diagonal to the horizon?

## Make it yours
- Make the first square deeper. See how D moves.
- Use D to draw a third square, between the first two.

## New words
- **diagonal point** — where the diagonal of a square meets the horizon.
- **depth** — how far a space reaches away from you.
- **foreshortened** — made to look shorter because it points away.
