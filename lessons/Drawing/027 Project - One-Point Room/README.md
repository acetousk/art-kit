# 027. Project - One-Point Room

**You make:** ~/Art/Drawing/027-one-point-room.kra  
**Builds on:** lessons 021 to 026  
**Time:** 60 min  
**Read:** Freehand Perspective and Sketching (Norton), PDF pages 123, 125–127; Perspective for Artists (Vicat Cole), PDF pages 34–35

## The idea
Draw the inside of a room. The back wall faces you as a true rectangle. The side walls, floor, and ceiling run to one point. Norton cuts off some ceiling and floor to improve the picture. A stool shows scale. "keeps the oblique lines from running to its corners, which should always be avoided" (Norton, PDF 127)

## Look
Norton PDF 123, Fig. 170: the finished room. PDF 125, Fig. 172: the room with its construction lines. PDF 126, Fig. 173: a floor diagonal used to measure distances.

## Steps
1. Open Krita. Make a new document, 3200 by 2400 px.
2. Add a horizon guide. Put it about two thirds of the way up.
3. Draw a rectangle for the back wall. Put the vanishing point inside it.
4. Pick the Assistant Tool. Add a Vanishing Point there.
5. From the vanishing point, draw a line through each corner of the back wall to the canvas edge.
   You should see: A box with an open front. All the lines run to the middle.
6. Draw a window on the right wall. Its top and bottom run to the point. Its sides are vertical.
7. Draw a door on the left wall in the same way.
8. Add a rug on the floor. Use a diagonal to find its depth.
9. Add a stool about one sixth of the room's height.
10. Choose a frame that cuts off some ceiling and floor. Draw the frame with the Rectangle Tool.
11. Add three values with the Fill Tool. Make the ceiling lightest and the floor darkest.
12. Press Ctrl + Shift + S. Save as ~/Art/Drawing/027-one-point-room.kra.

## Check your work
- Is the back wall a true rectangle?
- Do all other lines run to one point?
- Does the stool look the right size for the room?

## Make it yours
- Draw a hallway or a kitchen in one point.
- Draw your own bedroom from the doorway.

## New words
- **back wall** — the wall that faces you, parallel to the picture.
- **scale** — the size of one thing compared with others.
- **interior** — the inside of a room or building.
