# 005. Lines that show feeling

**You make:** ~/Art/Drawing/005-feeling-lines.kra  
**Builds on:** lesson 003  
**Time:** 30 min  
**Read:** Line and Form (Crane), PDF pages 31, 35–37

## The idea
Crane says that line is a language. A calm line lies flat. A broken or sharp line feels like action. A tall vertical line feels like rising. A bent line that falls feels sad. A wave-line shows movement. "broken curves and rectangular lines always suggest action and unrest" (Crane, PDF 31)

## Look
PDF 31: wave lines show movement and flat lines show rest. PDF 36: bowed lines that fall. PDF 37: a scale of line, from horizontal at one end to vertical at the other.

## Steps
1. Open Krita. Make a new document, 2400 by 1600 px.
2. Pick the Freehand Brush Tool and a pencil brush preset.
3. Pick the Rectangle Tool. In the Tool Options docker, set Fill to Not filled.
4. Draw six boxes in two rows. Leave space between them.
5. In box 1 draw long flat wavy lines. These are calm and restful.
6. In box 2 draw sharp zigzags and angles. These are action.
7. In box 3 draw tall straight lines that rise. These feel proud and strong.
8. In box 4 draw lines that bend and droop downward. These feel sad.
9. In box 5 draw wave lines like water. Make them repeat.
10. In box 6 draw a spiral that gets bigger. This feels full of energy.
   You should see: Six boxes, each with a different feeling.
11. Under each box, write one word for how it feels.
12. Press Ctrl + Shift + S. Save as ~/Art/Drawing/005-feeling-lines.kra.

## Check your work
- Does a flat line feel calm to you?
- Does a sharp zigzag feel like action?
- Did you draw each box with one kind of line only?

## Make it yours
- Draw the same house three times: calm, angry, and happy. Use only line type to show it.
- Draw a tree in the wind with wave lines.

## New words
- **horizontal** — flat, like the horizon.
- **undulating** — moving in smooth waves.
- **rhythm** — a pattern that repeats.
