# 034. Animation Frames and Onion Skin

**You make:** ~/Art/Painting/034-ball-frames.kra
**Builds on:** lesson 031
**Time:** 45 min
**Read:** Krita Manual, Animation with Krita; Krita Manual, Animation Timeline Docker; Krita Manual, Onion Skin Docker

## The idea
Animation is a set of pictures that play fast. Each picture is a frame. A keyframe is a frame you draw. Krita keeps the frames on a timeline. Onion skin shows the frames before and after yours in faint color. Start small: about 12 frames per second is easy for a beginner.

> "If you are just starting out, you are best off limiting yourself to 12 frames per second." (Krita Manual, Animation with Krita).

## Look
Animation with Krita: read the first section and the walk cycle part. Onion Skin Docker: read the first two paragraphs.

## Steps
1. Open Krita. Make a new 800 by 450 canvas. Name it ball frames.
2. Open Window ‣ Workspace ‣ Animation.
   You should see: The Animation Timeline Docker shows at the bottom.
3. Open the animation settings at the right end of the timeline. Set the frame rate to 12.
4. Add a new paint layer named ball. Do not animate the white background.
5. Right-click the first square of the ball row. Pick Create Blank Frame.
6. Draw a ball at the top left of the canvas.
   You should see: The square turns solid.
7. Click the lightbulb icon on the ball layer.
   You should see: Onion skin turns on.
8. Right-click the next square. Pick Create Blank Frame. Draw the ball a little lower and to the right.
   You should see: A faint green or red ball shows the other frame.
9. Add four more frames. Move the ball along a bouncing path.
10. On the last frame, draw the ball flat at the floor, as if it squashes.
11. Click Play in the timeline toolbar.
   You should see: The ball moves.
12. Drag across the Frame Timing Header to scrub through the frames.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/034-ball-frames.kra.

## Check your work
- Is a keyframe a frame you draw? (Yes.)
- Does onion skin show the frames before and after? (Yes.)
- Is 12 frames per second a good start? (Yes.)

## Make it yours
- Animate a leaf that falls with a wobble.
- Animate a blink with three frames.

## New words
- **frame** — one picture in an animation
- **keyframe** — a frame you draw yourself
- **onion skin** — a faint view of the next and last frames
