# 020. Palettes and Gamut Masks

**You make:** ~/Art/Painting/020-palette.kra
**Builds on:** lesson 019
**Time:** 40 min
**Read:** Krita Manual, Palette Docker; Krita Manual, Gamut Masks; Krita Manual, Artistic Color Selector Docker; Color Problems (Vanderpoel), PDF pages 126–127

## The idea
A palette is a small set of colors you choose before you paint. Fewer colors make a picture hang together. A gamut mask is a shape on the color wheel. You pick colors only inside the shape. Vanderpoel says to start with pairs and triads.

> "Constant practice in pairs and triads cannot be too fully recommended." (Vanderpoel, PDF page 126).

## Look
Page 126: read the lines about pairs, triads, and broken tints. Page 127: read the last lines about warm and cold tones. Gamut Masks: read How does it work?

## Steps
1. Open Krita. Make a new 2400 by 1600 canvas. Open the Palette Docker and the Artistic Color Selector Docker.
2. In the Palette Docker, click + to make a new palette. Name it my palette. Click Save.
3. Open the Gamut Masks Docker (Settings ‣ Dockers). Pick the mask Complementary.
4. In the Artistic Color Selector, switch the gamut mask on.
   You should see: Only colors inside the mask are easy to pick.
5. Pick one color. Click an empty swatch in the palette to add it. Add five colors in total.
6. Draw five boxes with a rectangle selection. Fill each with a palette color.
7. Switch the mask to Atmospheric Triad. Add three more colors to the palette.
8. Paint a small leaf and sky scene with only the palette colors. Use the Fill Tool and a soft brush.
9. Hold Ctrl and click a color in your scene. Check that it is in the palette.
10. Try one color that is not in the palette. Look at how it jumps out.
11. Save the palette. It stays in the Palette Docker.
12. Save the file with File ‣ Save As. Use the path ~/Art/Painting/020-palette.kra.

## Check your work
- Does a gamut mask limit your colors to a shape on the wheel? (Yes.)
- Does a small palette help a picture look the same in color? (Yes.)
- Is a triad three colors? (Yes.)

## Make it yours
- Make a palette from a leaf, a pot, and a sky. Paint a still life.
- Make a palette for a night scene and one for a desert.

## New words
- **palette** — a small set of colors you chose
- **gamut mask** — a shape on the color wheel that limits your colors
- **triad** — a set of three colors
