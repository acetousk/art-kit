# 033. Project Comic Page

**You make:** ~/Art/Painting/033-comic-page.kra
**Builds on:** lessons 028 to 032
**Time:** 60 min
**Read:** Krita Manual, Comic Panel Editing Tool; Krita Manual, Text Tool; Krita Manual, Stroke Selection; Pepper&Carrot ep10_Summer-Special/E10P03.kra

## The idea
Finish a three-panel page. Use the stack Revoy uses on a page from episode 10: a frame on top, a group for speech, and a group for the art. Panel 1 is a wide background. Panel 2 is a medium shot of your character. Panel 3 is a close face. Keep the lighting the same.

> "This tool allows you to add text to your artwork." (Krita Manual, Text Tool).

## Look
E10P03.kra: from the top, frame, the group speech (paint, bg), the group art (post, paint-over, Ink, top, bg).

## Steps
1. Open Krita. Open ~/Library/Painting/Pepper-and-Carrot/ep10_Summer-Special/E10P03.kra. Open the groups and look at the stack. Close the file with No.
2. Open ~/Art/Painting/032-page-panels.kra. Save it as 033-comic-page.kra.
3. Add a group named art below panel-frame. Add layers in it: bg, color, ink, texture.
4. Set ink to Multiply. Set texture to Soft Light at 40%.
5. Select panel 1 with the Rectangular Selection Tool. Paint a wide background from lesson 028 on bg.
6. Select panel 2. Paint your witch on the color layer. Use the flats method.
7. Select panel 3. Paint a close-up face. Add lines on the ink layer.
8. Add a group named speech above art. Add a layer named balloon.
9. Use the Elliptical Selection Tool to cut a balloon shape. Fill it white.
10. Open Edit ‣ Stroke Selection. Use a line in black. Click OK.
11. Pick the Text Tool. Click inside the balloon. Type a short line.
12. Move panel-frame to the top of the stack. Check the gutters.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/033-comic-page.kra.

## Check your work
- Does the page read from panel 1 to panel 3 with no doubt? (It should.)
- Is the speech group above the art group? (Yes.)
- Is the light the same in all panels? (It should be.)

## Make it yours
- Add a fourth panel with a sound word.
- Replace the text with a joke.

## New words
- **shot** — how near or far the view is in a panel
- **balloon** — the shape that holds speech in a comic
- **reading order** — the path your eye takes over the page
