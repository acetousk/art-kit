# 027. Project Revoy-Style Potion Piece

**You make:** ~/Art/Painting/027-potion-piece.kra
**Builds on:** lessons 022 to 026
**Time:** 60 min
**Read:** Pepper&Carrot ep06_The-Potion-Contest/E06P03.kra; Krita Manual, Flat Coloring; Krita Manual, Krita 4 Preset Bundle Overview

## The idea
Now paint your own small piece with Revoy's method. Put the line art on its own Multiply layer. Put flat colors in a group below it. Add shade and glow in layers. Put a Soft Light texture on top. The subject is a potion bottle with a glow.

> "Ink GPen: A preset with a dynamic on size to ink smoothly." (Krita Manual, Krita 4 Preset Bundle Overview).

## Look
Open your template revoy stack from lesson 025. Compare it with E06P03.kra.

## Steps
1. Open Krita. Press Ctrl+N. Under Templates, pick your template revoy stack.
2. Add a layer named sketch above background. Draw a potion bottle on a shelf with a Pencil preset.
3. Select the ink layer. Pick the preset Ink GPen. Draw clean lines over the sketch.
4. Hide the sketch layer.
5. In the group color, select the base layer. Use the Fill Tool on the bottle, cork, potion, and shelf.
6. Fill the wall on the background layer with a gradient.
7. Add a layer named shade above base, inside the group. Set it to Multiply. Turn on Alpha Inheritance.
8. Paint cool purple shade on it with a soft airbrush preset.
   You should see: Shade stays inside the shapes below.
9. Add a layer named glow. Set it to Screen. Paint a green glow around the bottle.
10. Select texture-harmony. Paint a soft texture over the page with a brush from a Textures family. Use gray.
11. Hide texture-harmony. Then show it again.
   You should see: The picture gains grain and richness.
12. Check values with a gray filter layer. Hide it again.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/027-potion-piece.kra.

## Check your work
- Is the ink layer set to Multiply? (Yes.)
- Is the texture layer set to Soft Light at a low opacity? (Yes.)
- Does the glow use Screen? (Yes.)

## Make it yours
- Paint a witch hat or a cat in the same stack.
- Keep the stack, but try warm light and cool shadow.

## New words
- **method** — a fixed way to do a task
- **flats group** — a group that holds the first solid colors
- **glow layer** — a Screen layer that adds light
