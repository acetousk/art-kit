# 016. Cubes, Cylinders and Cast Shadows

**You make:** ~/Art/Painting/016-forms.kra
**Builds on:** lesson 015
**Time:** 45 min
**Read:** Krita Manual, Polygonal Selection Tool; Krita Manual, Gradient Tool; Krita Manual, Arithmetic (Multiply)

## The idea
A flat-sided object like a cube has a flat tone on each face. The face toward the light is lightest. The face turned away is darkest. A round object like a cylinder changes smoothly. A cast shadow is the shadow an object throws on the floor. It uses Multiply, so the floor still shows through the shadow.

> "This is often used to color in a black and white lineart." (Krita Manual, Arithmetic, on Multiply).

## Look
Gradient Tool: see the Linear and Bilinear pictures. Arithmetic: read the paragraph on Multiply.

## Steps
1. Open Krita. Make a new 2400 by 1600 canvas. Fill the background with light gray.
2. Add a layer named cube top. Cut a diamond with the Polygonal Selection Tool. Fill it with near-white.
3. Add a layer named cube left. Cut the left face. Fill with mid gray.
4. Add a layer named cube right. Cut the right face. Fill with dark gray.
   You should see: Three tones make the cube look solid.
5. Add a layer named cylinder. Cut a tall rectangle body with a selection. Fill it with mid gray.
6. Select the body. Pick the Gradient Tool and the Linear shape.
7. Drag across the body from the left edge to the right edge.
   You should see: The cylinder looks round.
8. Add the top ellipse on its own layer. Fill it with light gray.
9. Add a layer named cast shadows. Set its blending mode to Multiply.
10. Cut a long shadow shape for each object, falling to the right and down. Fill it with mid gray.
11. Set the opacity of the shadow layer to 60%.
   You should see: You see the floor through the shadow.
12. Press Ctrl+Shift+A. Hide the shadow layer, then show it. Check that every shadow joins its object.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/016-forms.kra.

## Check your work
- Is the face turned toward the light the lightest? (Yes.)
- Does a cylinder need a smooth change of tone? (Yes.)
- Is the cast shadow layer set to Multiply? (Yes.)

## Make it yours
- Draw a cone and a box. Light them from the right.
- Draw three objects in a row. Cast all shadows in the same direction.

## New words
- **form** — a shape that looks solid, not flat
- **cast shadow** — the shadow an object throws on another surface
- **value** — how light or dark a color is
