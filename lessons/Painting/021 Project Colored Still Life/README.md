# 021. Project Colored Still Life

**You make:** ~/Art/Painting/021-colored-still-life.kra
**Builds on:** lessons 015 to 020
**Time:** 60 min
**Read:** Krita Manual, Mixing Colors; Krita Manual, Layers; Color Problems (Vanderpoel), PDF pages 85–86

## The idea
A still life is a picture of simple objects on a table. This project joins form, light, shadow, and color. Pick a warm light from one side. Use a palette of five colors. Paint each object with a light side, a shadow side, and a cast shadow. Keep the shadows cool and the lit side warm.

> "glazing is overlaying many different semi-transparent layers to create on-canvas color mixtures." (Krita Manual, Mixing Colors).

## Look
Vanderpoel page 86: read about the color of the sky in the shadow. Mixing Colors: read the glazing section.

## Steps
1. Open Krita. Make a new 2400 by 1600 canvas. Make a palette of five colors with the gamut mask.
2. Add a layer named table. Fill the top part with a wall color and the rest with a table color.
3. Add a layer named apple. Use a circle selection. Fill it with red. Turn on Alpha Lock.
4. Shade the apple with a soft brush. Make the upper left warm and the lower right a cool dark red.
5. Add a layer named cup. Use a rectangle with a bottom ellipse. Fill it with a light blue.
6. Use a Linear gradient inside the cup to make a round feel. Shade it from the same light.
7. Add a layer named box. Use the Polygonal Selection Tool. Paint three faces with three tones of a yellow-orange.
8. Add a layer named shadows. Set it to Multiply. Paint a cool purple shadow to the right of each object.
9. Blur the far end of each shadow with Filter ‣ Blur ‣ Gaussian Blur on a selection.
10. Add a layer named highlights. Paint small bright dots on the apple and the cup.
11. Add a gray filter layer (HSV/HSL Adjustment, Saturation -100). Check the values. Hide it.
12. Save the file with File ‣ Save As. Use the path ~/Art/Painting/021-colored-still-life.kra.

## Check your work
- Do all shadows point away from one light? (They should.)
- Is each lit side warmer than its shadow side? (It should be.)
- Does the gray view show clear light and dark? (It should.)

## Make it yours
- Paint the same still life with a cool light.
- Add a fourth object: a pear or a book.

## New words
- **still life** — a picture of objects that do not move
- **light source** — where the light comes from
- **glaze** — a thin see-through layer of paint over another
