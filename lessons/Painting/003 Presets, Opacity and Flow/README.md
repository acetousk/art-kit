# 003. Presets, Opacity and Flow

**You make:** ~/Art/Painting/003-presets-flow.kra
**Builds on:** lesson 002
**Time:** 35 min
**Read:** Krita Manual, Preset Docker; Krita Manual, Krita 4 Preset Bundle Overview; Krita Manual, Opacity and Flow

## The idea
A brush preset is a saved brush with all its settings. Krita ships with families of presets: Basic, Inking, Dry Painting, Wet painting, Blender, and more. Opacity and flow both set how see-through paint is. Opacity is for the whole stroke. Flow is for each stamp inside the stroke. Low flow builds color slowly, like a soft airbrush.

> "The transparency of separate dabs." (Krita Manual, Opacity and Flow, on Flow).

## Look
Krita 4 Preset Bundle Overview: read Basics, Inking, Dry Painting, Wet painting. Opacity and Flow: see the three strokes at the top.

## Steps
1. Open Krita. Make a new 2000 by 1400 canvas.
2. Find the brush presets docker. Click Basic-5 Size. Draw a short stroke.
3. Click the preset Ink Fineliner. Draw a stroke under the first one.
4. Click the preset Ink GPen. Draw a third stroke.
   You should see: The line gets thicker and thinner with pressure.
5. Click Basic_Wet. Draw a fourth stroke over the others.
   You should see: The wet brush mixes with colors under it.
6. Pick Basic-5 Size again. Set Opacity to 40% and Flow to 100%.
7. Draw a zigzag that crosses itself three times.
   You should see: Each stroke is even. Crossing makes no new layer of paint.
8. Set Opacity to 100% and Flow to 30%. Draw the same zigzag.
   You should see: Color builds up where the stamps overlap.
9. Pick a soft airbrush preset. Paint a soft cloud. Use low flow.
10. Pick a color. Paint a grass patch with a Dry Painting preset.
11. Next to each stroke, write the name of the preset with the Ink Fineliner.
12. Save the file with File ‣ Save As. Use the path ~/Art/Painting/003-presets-flow.kra.

## Check your work
- Does opacity set the see-through level of the whole stroke? (Yes.)
- Does a Wet preset mix with colors already on the canvas? (Yes.)
- Does low flow build color slowly as stamps overlap? (Yes.)

## Make it yours
- Find your three favorite presets. Write why you like each.
- Make a cloud with low flow and a rock with a hard Dry Painting preset.

## New words
- **preset** — a saved brush with all its settings
- **opacity** — how see-through a whole stroke is
- **flow** — how much paint each stamp adds
