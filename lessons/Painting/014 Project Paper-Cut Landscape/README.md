# 014. Project Paper-Cut Landscape

**You make:** ~/Art/Painting/014-paper-cut-landscape.kra
**Builds on:** lessons 008 to 013
**Time:** 60 min
**Read:** Krita Manual, Selections; Krita Manual, Gradient Tool; Krita Manual, Fill Tool; Krita Manual, Group Layers

## The idea
A paper-cut landscape uses flat shapes in layers, like cut paper. Each hill is a flat color. Far hills are paler and bluer. Near hills are darker. This project joins selections, fills, gradients, alpha lock, and groups. Each shape lives on its own layer, so you can swap its color or move it.

> "Selections allow you to pick a specific area of your artwork to change." (Krita Manual, Selections).

## Look
Look at your files 009 and 011. Plan five layers: sky, far hills, mid hills, near hills, and trees.

## Steps
1. Open Krita. Make a new 2400 by 1600 canvas.
2. Add a layer named sky. Fill it with a Linear gradient from blue to a pale peach.
3. Add a layer named sun. Use a circle selection and a Radial gradient for a glowing sun.
4. Add a layer named far hills. Use the Freehand Selection Tool to draw wavy hills. Fill with a pale blue-purple.
5. Add a layer named mid hills. Draw lower hills. Fill with a middle purple-green.
6. Add a layer named near hills. Draw the lowest hill. Fill with a dark green.
7. Add a layer named trees. Use the Polygonal Selection Tool to cut pine tree shapes. Fill them dark.
8. Duplicate the tree layer. Use Transform to make the copy smaller. Move it to the mid hills.
9. Turn on Alpha Lock on far hills. Paint a soft light band along the top with a soft brush.
10. Group the three hill layers and name the group land. Set the group above the sky.
11. Look at the picture with M pressed. Fix any shape that looks off.
12. Save the file with File ‣ Save As. Use the path ~/Art/Painting/014-paper-cut-landscape.kra.

## Check your work
- Are far hills paler than near hills? (They should be.)
- Is each shape on its own layer? (It should be.)
- Does the gradient sky lead your eye to the sun? (Yes or no.)

## Make it yours
- Paint the same land at night with three blues.
- Add a river with a feathered selection.

## New words
- **distance** — how far away a thing looks in a picture
- **silhouette** — a shape seen as one flat color
- **layer order** — the order of layers from back to front
