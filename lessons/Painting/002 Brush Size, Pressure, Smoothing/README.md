# 002. Brush Size, Pressure, Smoothing

**You make:** ~/Art/Painting/002-brush-control.kra
**Builds on:** lesson 001
**Time:** 30 min
**Read:** Krita Manual, Freehand Brush Tool; Krita Manual, Sensors; Krita Manual, Pixel Brush Engine

## The idea
A brush stamps its tip again and again along your stroke. Three things change the look: size, pressure, and smoothing. Pressure means how hard you press with the pen. A brush can turn pressure into a bigger size or a darker mark. Smoothing steadies a shaky line. Good control comes first, before any color.

> "Smoothing, also known as stabilising in some programs, allows the program to correct the stroke." (Krita Manual, Freehand Brush Tool).

## Look
Freehand Brush Tool: read the list under Smoothing (No Smoothing, Basic Smoothing, Weighted smoothing, Stabilizer). Sensors: find the line about Pressure.

## Steps
1. Open Krita. Make a new 2000 by 1400 canvas with Ctrl+N.
2. Press B for the Freehand Brush Tool.
3. In the brush presets docker, click the preset Basic-5 Size.
4. Set the brush size to 20 in the toolbar. Draw a line. Press lightly, then hard.
   You should see: The line changes as you press.
5. Set the size to 80. Draw one more line. Compare it to the first.
6. Open Tool Options. Set Smoothing to No Smoothing. Draw a long wave across the canvas.
7. Set Smoothing to Stabilizer. Draw the same wave below it.
   You should see: The new wave is smoother.
8. Draw a circle with each setting. Which circle is rounder?
9. Press F5 to open the brush editor. Click Size in the list. Look for the word Pressure.
10. Close the editor. Fill a row with ten short strokes. Press from light to hard across the row.
11. Write your name with Stabilizer on. Then write it with No Smoothing.
12. Save the file with File ‣ Save As. Use the path ~/Art/Painting/002-brush-control.kra.

## Check your work
- Does a harder press change the mark? (Yes, for most brushes.)
- Is the line behind your pen when Stabilizer is on? (Yes.)
- Is No Smoothing the fastest option, good for fine details? (Yes.)

## Make it yours
- Find the best smoothing for your hand. Use it for the next lessons.
- Draw a leaf with one stroke. Use pressure to make the middle wide.

## New words
- **pressure** — how hard you press the pen on the screen
- **smoothing** — a setting that steadies your line
- **brush tip** — the shape a brush stamps along the stroke
