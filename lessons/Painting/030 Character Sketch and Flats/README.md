# 030. Character Sketch and Flats

**You make:** ~/Art/Painting/030-character-flats.kra
**Builds on:** lesson 027
**Time:** 45 min
**Read:** Krita Manual, Mirror Tools; Krita Manual, Flat Coloring; Krita Manual, Krita 4 Preset Bundle Overview

## The idea
A character starts with simple shapes: a circle for the head, a triangle for the hat, an oval for the body. A front view is the same on the left and right. The mirror tools let you draw one side and see both. Then you clean up the lines. Each part gets a flat color on its own layer: skin, hair, hat, clothes. This is the Flat Coloring method from lesson 012.

> "Draw on one side of a mirror line while the Mirror Tool copies the results to the other side." (Krita Manual, Mirror Tools).

## Look
Mirror Tools: read the first paragraph and the options list. Preset Bundle Overview: read the Pencils and Inking parts.

## Steps
1. Open Krita. Make a new 2000 by 2800 canvas.
2. Add a layer named sketch. Pick a pencil brush preset. Draw the pose from simple shapes.
   You should see: A line shows down the middle.
3. Draw the left half of a witch: a hat, a face, hair, and shoulders.
   You should see: The right half appears.
4. If the strokes mirror up and down, use the other mirror tool instead.
5. Turn the mirror off. Add small changes to one side: a curl of hair, a pin on the hat.
6. Lower the opacity of sketch to 40%.
7. Add a layer named lines. Pick Ink GPen. Draw clean lines over the sketch. Set lines to Multiply.
8. Hide the sketch layer.
9. Add a group named color. Add a layer in it named skin. Fill the face and hands.
10. Add layers in the group: hair, hat, clothes. Fill each one under the lines layer.
11. Close gaps with a brush. Check that no white gaps show. Hide the lines to check.
12. Turn on Alpha Lock on each color layer. Check it.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/030-character-flats.kra.

## Check your work
- Does a mirror tool copy what you draw to the other side? (Yes.)
- Is each part on its own layer? (It should be.)
- Is the line layer above the colors? (Yes.)

## Make it yours
- Design a second hat and swap the layer.
- Draw a side view of the same head by hand, without mirror.

## New words
- **character** — a person or animal in a story
- **construction** — simple shapes you draw first to find the form
- **mirror tool** — a tool that copies your strokes to the other side
