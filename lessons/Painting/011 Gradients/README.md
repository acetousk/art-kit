# 011. Gradients

**You make:** ~/Art/Painting/011-gradients.kra
**Builds on:** lesson 010
**Time:** 35 min
**Read:** Krita Manual, Gradient Tool; Krita Manual, Fill Layers

## The idea
A gradient is a smooth change from one color to another. The Gradient Tool draws it when you drag across the canvas. The shape can be linear, radial, and more. A short drag makes a fast change. A long drag makes a slow change. Gradients make skies, glows, and soft light.

> "8 bits of color depth is not enough depth to make a truly smooth gradient." (Krita Manual, Gradient Tool).

## Look
Gradient Tool: look at the pictures for Linear and Radial. Read the Dither paragraph.

## Steps
1. Open Krita. Make a new 2400 by 1600 canvas. Add a layer named sky.
2. Set the foreground to a deep blue. Set the background to a pale orange.
3. Pick the Gradient Tool. In Tool Options, pick a gradient from foreground to background.
4. Set Shape to Linear. Drag from the top to the horizon.
   You should see: The sky fades from blue to orange.
5. Undo with Ctrl+Z. Drag a shorter line.
   You should see: The change is faster.
6. Drag a longer line past the horizon.
   You should see: The change is slower. Keep the one you like.
7. Add a layer named sun. Pick the Elliptical Selection Tool. Draw a circle low in the sky.
8. Set the foreground to white and the background to yellow.
9. Pick the Gradient Tool. Set Shape to Radial. Drag from the center of the circle outward.
   You should see: The sun is bright in the middle.
10. Deselect. Add a layer named ground. Select the bottom third with a rectangle.
11. Drag a Linear gradient from dark to a lighter green.
   You should see: The ground gets lighter toward the horizon.
12. Save the file with File ‣ Save As. Use the path ~/Art/Painting/011-gradients.kra.

## Check your work
- Does a longer drag make a slower color change? (Yes.)
- Does Radial start from the point where you press? (Yes.)
- Does a selection keep the gradient inside its edge? (Yes.)

## Make it yours
- Paint a night sky with a gradient from black to purple.
- Make a lamp glow with a Radial gradient on its own layer.

## New words
- **gradient** — a smooth blend from one color to another
- **linear** — in a straight line
- **radial** — from a center point outward
