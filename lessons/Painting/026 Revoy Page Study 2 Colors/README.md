# 026. Revoy Page Study 2 Colors

**You make:** ~/Art/Painting/026-revoy-colors.kra
**Builds on:** lesson 025
**Time:** 45 min
**Read:** Pepper&Carrot ep06_The-Potion-Contest/E06P05.kra; Pepper&Carrot ep20_The-Picnic/E20P03.kra; Krita Manual, Color Sampler Tool; Krita Manual, Palette Docker

## The idea
You can learn color from a pro by sampling it. The Color Sampler Tool picks a color from the canvas. It can pick from one layer only, so you see the colors before the texture. Pick a light, a middle, and a dark from each area. Write them down as a palette.

> "This tool allows you to choose a point from the canvas and make the color of that point the active foreground color." (Krita Manual, Color Sampler Tool).

## Look
E06P05.kra: color group (top2, top1, base). E20P03.kra: layers frame, texture, col. Color Sampler Tool: find the first drop-down for the layer choice.

## Steps
1. Open Krita. Open ~/Library/Painting/Pepper-and-Carrot/ep06_The-Potion-Contest/E06P05.kra. Do not save over it.
2. Open the Palette Docker. Make a new palette named revoy ep6.
3. Pick the Color Sampler Tool. In Tool Options, sample the current layer only.
4. In Tool Options, set the tool to add colors to a color palette.
5. Click the base layer. Click three areas of the page.
   You should see: Three colors join the palette.
6. Click top1, then top2. Sample one light color and one dark color from each.
7. Close the file. Click No when Krita asks to save.
8. Open ~/Library/Painting/Pepper-and-Carrot/ep20_The-Picnic/E20P03.kra. Click the col layer. Sample five colors from it.
9. Set the sampler to read all visible layers. Sample one spot. Hide texture, then sample it again.
   You should see: The two colors differ a little.
10. Make a new 2400 by 1200 canvas. Draw 12 boxes. Fill them with your sampled colors.
11. Put the warmest colors on the left and the coolest on the right.
12. Write a note with the Text Tool. Say which hue is the most pure and which is the darkest.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/026-revoy-colors.kra.

## Check your work
- Can the Color Sampler pick from one layer only? (Yes.)
- Does a texture layer change the colors a little? (Yes.)
- Does a good page use only a few main colors? (Often yes.)

## Make it yours
- Sample the colors from a page you like. Build a palette.
- Paint a small scene with only your palette.

## New words
- **sample** — pick a color from the canvas
- **local color** — the color an object has in plain light
- **swatch** — a small box of one color
