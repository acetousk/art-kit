# 007. Project Layered Brush Garden

**You make:** ~/Art/Painting/007-brush-garden.kra
**Builds on:** lessons 001 to 006
**Time:** 55 min
**Read:** Krita Manual, Introduction to Layers and Masks; Krita Manual, Group Layers; Krita Manual, Krita 4 Preset Bundle Overview

## The idea
This project uses all your first skills: canvas, brush families, flow, and layers. You paint a small garden. The sky, the ground, and the flowers each live on their own layer. You group them, and you copy shapes with the Transform Tool. A clean layer stack means you can fix one part without touching the rest.

> "Layers can give better control over your artwork" (Krita Manual, Introduction to Layers and Masks).

## Look
Look at your files 003, 004, and 006. Pick one brush family from 004 for each part of the garden.

## Steps
1. Open Krita. Make a new 2400 by 1600 canvas. Name the document garden.
2. Add a layer named sky. Paint it with a soft airbrush preset. Use low flow and a light blue.
3. Add a layer named grass. Use a Dry Painting preset. Paint the ground green.
4. Add a layer named far flowers. Use a small Basic preset. Paint ten small flowers.
5. Group the three layers. Name the group back.
6. Add a layer named big flower. Paint one large flower with petals, a center, and a stem.
7. Use Duplicate Layer or Mask three times. Name each copy flower 2, flower 3, flower 4.
8. Move each copy. Use the Transform Tool to change size and turn.
   You should see: You see a small bunch.
9. Group the four flower layers. Name the group front.
10. Add a layer named sun in the back group. Paint a yellow sun with a Wet preset.
11. Lower the opacity of the far flowers layer to 70%.
   You should see: The far flowers look further away.
12. Set the group front above the group back. Check the order. Hide and show each group.
13. Save the file with File ‣ Save As. Use the path ~/Art/Painting/007-brush-garden.kra.

## Check your work
- Is each part of the garden on its own layer? (It should be.)
- Do the far flowers look further away than the near ones? (They should.)
- Did you use at least three brush families? (Yes or no.)

## Make it yours
- Paint a night garden with the same layers.
- Add fog: a new layer with a soft preset and low flow.

## New words
- **project** — a bigger piece that uses many old skills
- **foreground** — the part of a picture closest to you
- **background** — the part of a picture far from you
