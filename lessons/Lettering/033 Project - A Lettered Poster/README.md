# 033. Project - A Lettered Poster

**You make:** ~/Art/Lettering/33-lettered-poster.kra
**Builds on:** lessons 031 and 032
**Time:** 60 min
**Read:** Speedball, PDF pages 15 (right half), 17 (right half), 18 (left half), 22 (left half) and 24 (left half)

## The idea
This project makes a real poster. Plan the layout first, then pick the letter styles. Speedball says the show-card letterer must make a lot of work fast, so use a few simple styles and a clear plan. Use one style for the title, and one plain style for the details. Keep colors to black and one other color.

> "One Stroke" (Speedball, PDF p. 18, left half)

## Look
Speedball page 18, left half: see the price tickets and the show cards. Notice that each uses only one or two letter styles. Page 22, left half: see poster letters with outlines.

## Steps
1. Open Krita. Press Ctrl+N. Make a 1800 by 2400 px image. Save it as 33-lettered-poster.kra.
2. Show the grid at 40 px.
3. Plan a poster for a real event: a bake sale, a club, or a concert.
4. Write the text on a spare layer with the Text tool. Keep it to 12 words.
5. Sketch three small layouts on a Thumbs layer. Pick the best one.
6. Draw the final layout as gray blocks on a Blocks layer. Put the main block near the optical center.
7. Add a Title layer. Build the title in block letters with the Rectangle tool.
8. Add a Details layer. Letter the details in monoline capitals with Ink-2 Fineliner.
9. Add a thin border with the Rectangle tool. Leave liberal margins.
10. Pick one color. Use the Fill tool on the title letters. Keep the details black.
   You should see: the title strong, the details quiet.
11. Hide Blocks and Thumbs. Stand back. Can you read the title from across the room?
12. Fix any letter that is hard to read. Fix one spacing problem.
13. Press Ctrl+S to save to ~/Art/Lettering/33-lettered-poster.kra.

## Check your work
- Can you read the main words from across the room?
- Does the layout have clear groups with space between?
- Did you use only one other color besides black?

## Make it yours
- Make a second poster for a different event.
- Try the same text with a different layout.

## New words
- **show card** — a small lettered sign for a shop or event
- **title** — the main words of a poster
- **details** — the small facts: time, place, price
