# 025. Blackletter, Even Color

**You make:** ~/Art/Lettering/25-blackletter.kra
**Builds on:** lesson 024
**Time:** 40 min
**Read:** Brown, PDF pages 156, 158 and 197; Johnston, PDF page 51

## The idea
Blackletter is the narrow, angular late Gothic. Brown says no circles are used. All corners are sharp. The first rule is uniform color. The white between letters should be about the same as the space between the stems. Brown says this style looks best when it is very dark. He warns that a pencil outline cannot show the final color.

> "The first essential of a good Blackletter line or page is that it shall be of a uniform color." (Brown, PDF p. 158)

## Look
Brown page 197: see the Albrecht Durer small letters. Notice how many strokes look alike. Page 158: read how the space between letters matches the space between stems.

## Steps
1. Open Krita. Open 24-round-gothic.kra and Save As 25-blackletter.kra.
2. Hide the old layer. Add a vector layer named Black.
3. Pick the Calligraphy tool at Width 36, Fixation 1, Angle 45.
4. Draw 10 straight vertical strokes with sharp ends. Make each end a small slanted cut.
5. Draw the letters i, n, m, u. Use no round parts. Make the corners sharp.
6. Draw o with a hexagon shape. Draw e and a with angled strokes.
7. Write the word minimum. Space the stems evenly, about as far apart as the width of the white inside n.
   You should see: a dark, regular pattern.
8. Squint at the word. Are there light or dark spots? Fix any odd gap.
9. Write the word manuscript. Keep the same color all the way.
10. Press Ctrl+S to save to ~/Art/Lettering/25-blackletter.kra.

## Check your work
- Do your letters have sharp corners, not round ones?
- Is the spacing between stems the same all across the word?
- Does the word look like an even dark pattern?

## Make it yours
- Write a line of text in blackletter.
- Make the spaces wider. How does the color change?

## New words
- **blackletter** — a narrow, dark, angular Gothic lettering
- **uniform color** — an even darkness across the line
- **stem** — the main upright stroke of a letter
