# 031. Poster Letters, Block and Heavy Capitals

**You make:** ~/Art/Lettering/31-block-letters.kra
**Builds on:** lesson 011
**Time:** 40 min
**Read:** Speedball, PDF page 24 (left half); Speedball, PDF page 22 (left half); Speedball, PDF page 34 (left half)

## The idea
Poster letters are big and plain so people can read them from far away. Speedball shows Block Letters with square ends, and a Plain Gothic with even strokes. His page called Building up letters shows how a heavy letter is built from the same strokes as a thin one, made thicker. Keep the white spaces inside letters open.

> "Square finish letters are made with a Style A square pointed pen" (Speedball, PDF p. 24, left half)

## Look
Speedball page 24, left half: see BLOCK LETTERS above PLAIN GOTHIC. Page 34, left half: see Heavy-Face Roman Capitals built up from thin strokes. Page 22, left half: see the Double-Stroke Poster Method of Construction.

## Steps
1. Open Krita. Press Ctrl+N. Make a 2400 by 1600 px image. Save it as 31-block-letters.kra.
2. Show the grid at 40 px with Snap on. Add a paint layer named Guides.
3. Draw lines at y = 240 and 560.
4. Add a paint layer named Block. Pick the Rectangle tool. Set Fill to Foreground color and Outline to No Outline.
5. Draw L: a stem 3 cells wide and 8 cells tall, then a foot 3 cells tall along the base.
6. Draw B, in order: a stem, then two rectangles for the top and bottom bows.
7. Add a counter to each bow. Set the Background color to white.
8. Set Fill to Background color and draw a small rectangle inside.
   You should see: letters with open white holes.
9. Pick the Ellipse tool. Draw O as a black ellipse with a white ellipse inside.
10. Draw C like O, then cut the right side with a white rectangle.
11. Draw K: a stem plus two diagonals. Use the Polygon tool with Fill set to Foreground color.
12. Add a square serif block at each stroke end to match Speedball's Block Letters.
13. Look at the word BLOCK. Are the white spaces inside letters open and clear?
14. Press Ctrl+S to save to ~/Art/Lettering/31-block-letters.kra.

## Check your work
- Are all the strokes the same weight?
- Are the white holes inside B, O, and K still open?
- Could you read the word from across the room?

## Make it yours
- Build the letters of your first name as block letters.
- Make a version with stems 2 cells wide. Which reads better?

## New words
- **block letter** — a heavy, plain letter with square ends
- **counter** — the white hole inside a letter
- **poster letter** — a big plain letter made to be read from far away
