# 021. Round Hand Script, Strokes and Coupling

**You make:** ~/Art/Lettering/21-round-hand.kra
**Builds on:** lesson 020
**Time:** 40 min
**Read:** Speedball, PDF pages 18 (right half) and 20 (right half); Johnston, PDF pages 77, 80 and 81

## The idea
Script is a joined handwriting. Speedball shows round hand with groups of similar letters. The letters lean and flow into each other. Johnston calls the joining stroke a coupling. It lets you write faster. But he says to join below the letter when you can, and to take care where joins hurt reading.

> "Coupling is for convenience and legibility, and where it tends to interfere with legibility, we must be careful." (Johnston, PDF p. 81)

## Look
Speedball page 20, right half: see the rows of small letters in word groups: in union wine mine. Page 18, right half: see the slant lines and the letter groups.

## Steps
1. Open Krita. Open 19-italic-guides.kra and Save As 21-round-hand.kra.
2. Keep the Guides and Slant layers. Hide the Italic layer. Add a paint layer named Script.
3. Pick Ink-2 Fineliner at 10 px. Draw an oval, leaning right, then a stem. This is the shape of a.
4. Warm up: draw a row of connected loops leaning right. Draw a row of connected humps like n n n.
5. Write the group u n i m w.
   You should see: each letter leans along the slant lines and joins the next.
6. Write the group c o e a d g.
7. Write the words: in union, wine mine, move vine.
8. Join the letters with the coupling stroke. Join below where you can.
9. Find one join that hurts reading. Redo it with a gap.
10. Press Ctrl+S to save to ~/Art/Lettering/21-round-hand.kra.

## Check your work
- Do all strokes lean the same way?
- Does each letter join the next with a smooth stroke?
- Can you read every word easily?

## Make it yours
- Write your full name in script.
- Write a short sentence and count the joins that need a gap.

## New words
- **script** — joined, flowing handwriting
- **coupling** — the stroke that joins one letter to the next
- **round hand** — a script with round, smooth letter shapes
