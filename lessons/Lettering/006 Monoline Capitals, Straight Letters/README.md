# 006. Monoline Capitals, Straight Letters

**You make:** ~/Art/Lettering/06-monoline-straight-caps.kra
**Builds on:** lesson 002
**Time:** 30 min
**Read:** Speedball, PDF page 7 (right half); Speedball, PDF page 24 (left half)

## The idea
A monoline letter has one line weight, like a plain pen. Speedball builds the capitals from straight strokes and curves in a fixed order. Start with the letters made only of straight lines. Keep every stroke the same width. Make every letter the same height.

> "Arrows indicate direction of strokes and numbers the order in which they are made" (Speedball, PDF p. 7, right half)

## Look
Page 7, right half, top: see the title Elementary Principles of Letter Construction. Arrows show direction and numbers show order. Page 24, left half, bottom: see the Plain Gothic alphabet.

## Steps
1. Open Krita. Open lettering-sheet.kra and Save As 06-monoline-straight-caps.kra.
2. On Guides, draw two lines 8 cells (320 px) apart for row 1: y = 160 and y = 480.
3. Use the line tool with snap.
4. Repeat for row 2: y = 640 and y = 960.
5. Repeat for row 3: y = 1120 and y = 1440.
6. Add a paint layer named Caps. Pick Ink-2 Fineliner at 12 px.
7. Row 1: draw I L T H E F. Draw the stems first. Leave 2 cells between letters.
8. Row 2: draw A V W X Y Z. Use the line tool (V) for each stroke.
   You should see: every letter fills the space from line to line.
9. Row 3: draw K M N. Draw M with vertical outside strokes and two diagonals.
10. Check each letter. Is each stroke the same width? Is each letter on the base line?
11. Press Ctrl+Z on any letter that is too tall. Draw it again.
12. Press Ctrl+S to save to ~/Art/Lettering/06-monoline-straight-caps.kra.

## Check your work
- Do all letters touch both guide lines?
- Is every stroke the same width?
- Did you draw the stems before the bars?

## Make it yours
- Write your initials in monoline capitals.
- Make a second row 12 px wide and a third row 24 px wide. Compare.

## New words
- **monoline** — a letter made with one line weight
- **cap height** — the height of a capital letter, from base line to top line
- **overlap** — to cross a little so two strokes join cleanly
