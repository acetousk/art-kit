# 002. Five Guide Lines for Easy Lettering

**You make:** ~/Art/Lettering/02-five-lines.kra
**Builds on:** lesson 001
**Time:** 30 min
**Read:** Speedball, PDF page 9 (right half); Johnston, PDF page 262; Brown, PDF page 228

## The idea
Speedball ruled five lines with four equal spaces. Each line has a name. Capitals and tall letters reach line 1. Normal small letters fill the middle. Letters like g, p and y hang down to line 5. The plate says this scheme is for beginners and not for all work. Later lessons use better proportions.

> "The beginner will find it always wise to base his lettering on penciled top and bottom guide lines." (Brown, PDF p. 228)

## Look
Speedball page 9, right half, middle: the labels run Ascenders, Top Line, Waist Line, Base Line, Descenders. Check where Bbde Ahoy sits, and where g j p q y hang.

## Steps
1. Open Krita. Open ~/Art/Lettering/lettering-sheet.kra. Save it as 02-five-lines.kra with Ctrl+Shift+S.
2. Select the Guides layer. Pick the Ink-2 Fineliner at 4 px. Press V for the line tool.
3. Draw five lines across the canvas at y = 160, 240, 320, 400 and 480 px.
   You should see: five lines with four equal spaces of 80 px, like a music staff.
4. Draw a second set of five lines at y = 800, 880, 960, 1040 and 1120 px.
5. Add a paint layer named Letters. Pick the Pencil-2 preset at size 8 px.
6. In band 1, write the capitals A and B. Start each on line 4 and reach up to line 1.
7. Write b, d, e, h, o and y next to them. Tall letters reach line 1.
8. Normal letters fill lines 2 to 4.
9. In band 2, write a c e i m n o r s u v w x z.
10. Keep each of these letters between line 2 and line 4.
11. Add g j p q y with tails that reach line 5.
12. Look at your row. Name each line aloud: Ascender, Top, Waist, Base, Drop.
13. Press Ctrl+S to save the file to ~/Art/Lettering/02-five-lines.kra.

## Check your work
- Do all capitals and normal small letters rest on line 4?
- Do g, p and y reach line 5?
- Are the four spaces between the lines equal?

## Make it yours
- Write your name between the lines.
- Write the word jumping and check every tail.

## New words
- **base line** — the line that capitals and normal small letters rest on
- **ascender** — a part of a letter that rises above the normal height
- **descender** — a part of a letter that drops below the base line
