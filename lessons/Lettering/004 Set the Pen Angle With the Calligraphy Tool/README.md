# 004. Set the Pen Angle With the Calligraphy Tool

**You make:** ~/Art/Lettering/04-pen-angle.kra
**Builds on:** lesson 003
**Time:** 35 min
**Read:** Brown, PDF page 26; Johnston, PDF pages 67 and 69; Speedball, PDF page 7 (left half); Krita Manual, Calligraphy Tool

## The idea
A flat pen makes thick and thin lines. The line is thick when you move the pen across its wide edge. It is thin when you move along the edge. The angle of the pen decides which strokes are thick. Krita's Calligraphy tool has an Angle setting, so you can copy a flat pen. Roman capitals use about 45 degrees. Upright round hand uses an almost flat angle.

> "It is the chisel edge of the nib which gives the "clean cut" thick and thin strokes" (Johnston, PDF p. 67)

## Look
Brown page 26: read how the early scribes held the reed pen and what a 45 degree stroke does. Speedball page 7, left half: see the title Eccentric Title made with a Style C pen held at 45 degree angle.

## Steps
1. Open Krita. Open 03-strokes.kra and Save As 04-pen-angle.kra.
2. In the Layers docker, click the arrow next to the Add layer button. Choose Add Vector Layer.
3. Pick the Calligraphy tool in the toolbox. Open the Tool Options docker.
4. Set Width 40, Fixation 1, Angle 45. Turn off Use Tablet Pressure. Set Thinning 0.
5. Draw a diagonal stroke from top left to bottom right.
   You should see: a thick stroke. If it is thin, set Angle to 135 and try again.
6. Draw a diagonal from bottom left to top right.
   You should see: a thin stroke, the opposite of the first.
7. Draw a row of 8 vertical strokes. Then a row of 8 horizontal strokes. Compare their thickness.
8. Add a new vector layer. Set Angle to 0. Draw 8 vertical strokes and 8 horizontal strokes.
   You should see: vertical strokes thick, horizontal strokes thin.
9. Draw an O at Angle 0, then at Angle 45. Where is each O thickest?
10. Write the angle you used next to each row. Use the Text tool and click on the canvas.
11. Press Ctrl+S to save to ~/Art/Lettering/04-pen-angle.kra.

## Check your work
- At Angle 0, are the horizontal strokes the thinnest?
- Does a stroke along the pen's edge look thin?
- Does the O change its thick part when you change the angle?

## Make it yours
- Try Angle 30 and write your name.
- Set Fixation to 0.5. What happens to the thin strokes?

## New words
- **nib** — the tip of a pen that touches the paper
- **pen angle** — the angle of the flat nib against the line you write on
- **contrast** — the difference between thick and thin parts
