# 017. Project Flats and Shading on a Page

**You make:** ~/Art/Revoy/017-project-page-shading.kra  (new file, copied from lesson 016)
**Builds on:** lessons 008, 015 and 016
**Time:** 60 min
**Read:** David Revoy, "Episode 38 Production Report", sections Character Color-Flat and Shading

## The idea
Revoy paints the characters under a neutral light first. Then he shades them in a group. He says: "I paint the characters under a neutral light." (David Revoy, Episode 38 Production Report). Use the same light colors in every panel. Then the page looks like one set.

## Look
In the production report, read the Character Color-Flat part. Then read the Shading part.

## Steps
1. Open ~/Art/Revoy/016-page-panels.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/017-project-page-shading.kra.
3. In panel 1, add a paint layer. Paint flat colors on the characters with the Fill Tool.
4. Select the flat layer. Choose Layer ‣ Quick Clipping Group.
5. Add a shade layer above the flat layer, inside the group. Set Hard Light.
6. Fill the shade layer with RGB 127, 127, 127.
7. Paint dark shadows and pale light on the shade layer.
8. Repeat steps 3 to 7 for panel 2.
9. Repeat steps 3 to 7 for panel 3.
   You should see: All panels use the same light side.
10. Hide the shade layers, then show them again.
11. Save the file.

## Check your work
- Do all panels use the same light colors? (Yes.)
- Does the shade stay inside the group? (Yes.)
- Is this page finished? (No, it has shade only.)

## Make it yours
- Shade panel 1 with a warm light and panel 2 with a cool light.
- Shade one character with three gray steps only.

## New words
- **neutral light** — an even light that does not favor one side
- **color palette** — the set of colors you use
- **Quick Clipping Group** — a Krita command that groups layers and adds a shade layer
