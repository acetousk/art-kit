# 016. Panels with the Comic Panel Tool

**You make:** ~/Art/Revoy/016-page-panels.kra  (new file, copied from lesson 015)
**Builds on:** lesson 015
**Time:** 35 min
**Read:** David Revoy, "Tutorial: a Comic strip from A to Z with Krita", chapter Panels; Krita Manual, Comic Panel Editing Tool

## The idea
Panels divide a page into boxes. They set the order that readers follow. Revoy says: "The fundamental stone of getting a comic easy to read!" (David Revoy, Tutorial: a Comic strip from A to Z with Krita). The comic panel tool is in the toolbox.

## Look
In the comic tutorial, read the chapter Panels. In the Krita Manual, find the Comic Panel Editing Tool.

## Steps
1. Open ~/Art/Revoy/015-page-sketch.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/016-page-panels.kra.
3. Pick the Comic Panel Editing Tool from the toolbox.
4. Draw one wide panel across the top of the page.
5. Press Ctrl+Z if a panel lands in the wrong place.
6. Draw the other panels below it. Use different sizes.
7. Make the main moment the biggest panel.
   You should see: The page splits into clear boxes.
8. Save the file.

## Check your work
- Do panels control the reading order? (Yes.)
- Must every panel be the same size? (No.)
- Is the main moment the biggest panel? (Usually yes.)

## Make it yours
- Make a three-panel strip with one wide panel at the bottom.
- Make a page with one big panel and four small ones.

## New words
- **reading order** — the order in which the eye reads panels
- **toolbox** — the Krita panel with all the tools
- **comic strip** — a short story in a row of panels
