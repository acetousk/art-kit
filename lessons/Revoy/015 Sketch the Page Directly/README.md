# 015. Sketch the Page Directly

**You make:** ~/Art/Revoy/015-page-sketch.kra  (new file, copied from lesson 014)
**Builds on:** lesson 014
**Time:** 40 min
**Read:** David Revoy, "Episode 39 Production Report (wip)", section Sketching

## The idea
For episode 39, Revoy stopped making many small thumbnails. He drew on each page file. He starts with a thick sketch. He says: "First, I'm creating a thick sketch in mid-gray on a white background." (David Revoy, Episode 39 Production Report). The sketch is rough. It is a guide only.

## Look
In the Sketching part, read how he uses a flat brush and mid-gray.

## Steps
1. Open ~/Art/Revoy/014-page-thumbnails.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/015-page-sketch.kra.
3. Add a new paint layer at the bottom. Fill it with white.
4. Add a new paint layer above it. Name it sketch.
5. Set the color to RGB 127, 127, 127.
6. Pick b4) Basic Size Pressure - deevad 25. Draw the figures roughly.
   You should see: Thick, rough shapes on a white page.
7. Pick the Rectangle Tool. Sketch three panel boxes.
8. Save the file.

## Check your work
- Is the first sketch thick and rough? (Yes.)
- Is the sketch mid-gray on white? (Yes.)
- Does one page file hold the whole sketch? (Yes.)

## Make it yours
- Sketch a second page with two panels only.
- Sketch a page of one big panel and one small panel.

## New words
- **sketch** — a rough drawing that guides the final work
- **mid-gray** — a gray halfway between black and white
- **panel** — one box of a comic page
