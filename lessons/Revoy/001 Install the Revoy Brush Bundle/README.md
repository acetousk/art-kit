# 001. Install the Revoy Brush Bundle

**You make:** ~/Art/Revoy/001-brush-test.kra  (new file)
**Builds on:** nothing
**Time:** 25 min
**Read:** David Revoy, "Krita brushes 2025-01 bundle", sections Install and License

## The idea
David Revoy shares his brushes as one bundle. A bundle is one file with many brush presets. You import it once. Then the brushes show in Krita. The brushes are free, so you can use them for any work.

> "you'll find the brush in the tag deevad 25.01" (David Revoy, Krita brushes 2025-01 bundle).

## Look
In the article, read the Install section. It has five short steps. Compare them with the steps below.

## Steps
1. Open Krita.
2. Click Settings ‣ Manage Resources… in the menu.
3. Click the import button.
4. Open ~/Library/Painting/Brushes. Select Deevad_25.01.bundle. Click Open.
   You should see: The bundle appears in the resource list.
5. Close the dialog.
6. Press Ctrl+N. Make a new file, 2400 by 1600 pixels.
7. Open the Brush Presets docker if it is not open.
8. Open the tag list. Pick the tag deevad 25.01.
   You should see: Many brush presets with "deevad 25" in their names.
9. Pick one brush. Draw a short line on the canvas.
10. Pick a second brush. Draw another line.
11. Save the file with File ‣ Save As. Use ~/Art/Revoy/001-brush-test.kra.

## Check your work
- Is the bundle one file with many brush presets? (Yes.)
- Does the tag deevad 25.01 show the new brushes? (Yes.)
- Does the brush bundle need internet after import? (No.)

## Make it yours
- Pick your favorite brush. Draw a small scene with it.
- Pick two brushes from the same tag. Write how their lines differ.

## New words
- **bundle** — one file with many brush presets
- **tag** — a label that groups brush presets
- **preset** — a saved brush with fixed settings
