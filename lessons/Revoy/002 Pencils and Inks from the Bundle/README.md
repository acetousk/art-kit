# 002. Pencils and Inks from the Bundle

**You make:** ~/Art/Revoy/002-pencils-inks.kra  (new file)
**Builds on:** lesson 001
**Time:** 30 min
**Read:** David Revoy, "Krita brushes 2025-01 bundle", section Changelog

## The idea
The bundle uses letters and numbers to group its brushes. Group c holds pencils and thin lines. Pencil H Sketch is for rough guide lines. Revoy says: "Kept the design, and color code by groups" (David Revoy, Krita brushes 2025-01 bundle).

## Look
In the Brush Presets docker, find the names that start with c1), c2), c4) and b5).

## Steps
1. Open Krita. Press Ctrl+N. Make a new file, 2000 by 1400 pixels.
2. Open the Brush Presets docker. Find c1) Pencil H Sketch - deevad 25.
3. Draw three light, thin lines with c1).
   You should see: Light lines for a rough sketch.
4. Pick c2) Pencil 2B - deevad 25. Draw one dark line over a light line.
5. Pick c4) Bristles Lineart - deevad 25. Draw one curved outline.
6. Pick b5) Thin Basic Details - deevad 25. Add three small details.
7. Press Ctrl+Z to undo a stroke that is wrong.
8. Compare the four lines. Notice what each brush changes.
9. Save the file with File ‣ Save As. Use ~/Art/Revoy/002-pencils-inks.kra.

## Check your work
- Does the bundle name each brush with a letter and a number? (Yes.)
- Do different brushes make different lines? (Yes.)
- Is one brush enough for a whole picture? (No.)

## Make it yours
- Draw a leaf with the pencil brush. Then ink its edge with the line brush.
- Make three lines with each brush. Put them side by side.

## New words
- **group** — brushes that share a letter in their name
- **stroke** — one line made by one drag of the pen
- **undo** — remove the last stroke
