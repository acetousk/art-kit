# 013. Magic Glow with Screen and Blur

**You make:** ~/Art/Revoy/013-magic-glow.kra  (new file, copied from lesson 009)
**Builds on:** lesson 009
**Time:** 35 min
**Read:** David Revoy, "Turbulence for Magic Effects, Krita tutorial"; Krita Manual, Blur (Filters)

## The idea
Revoy shows magic with a glow. His video uses a G'MIC filter. This lesson uses only Krita tools. You paint a swirl, blur it, and set it to Screen. He says: "If you like to paint magic powers, this new tutorial is for you!" (David Revoy, Turbulence for Magic Effects).

## Look
In the video page, read the timeline item Layer effect for the outer glow. Only read it. You do not need it here.

## Steps
1. Open ~/Art/Revoy/009-light-glow.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/013-magic-glow.kra.
3. Add a new paint layer above glow. Name it magic.
4. Pick b1) Airbrush - deevad 25. Pick a purple. Paint a swirl around the main object.
5. Open the Gaussian Blur filter from the Filters menu. Set the radius to about 10 pixels.
   You should see: The swirl looks soft and glowing.
6. Set the magic layer blending mode to Screen.
7. Add one more paint layer above magic. Pick light violet. Paint a small bright spot.
8. Save the file.

## Check your work
- Does blur make the glow soft? (Yes.)
- Is Screen a good mode for light? (Yes.)
- Do you need G'MIC for this lesson? (No.)

## Make it yours
- Paint a green glow around a potion bottle.
- Paint a glowing sword with a blue swirl.

## New words
- **G'MIC** — a filter plug-in. This lesson does not use it.
- **swirl** — a curved line that turns around
- **radius** — the size of a blur
