# 007. Colorize Mask for Quick Color

**You make:** ~/Art/Revoy/007-colorize.kra  (new file, copied from lesson 005)
**Builds on:** lesson 005
**Time:** 35 min
**Read:** David Revoy, "Krita Colorize-Mask: Advanced Tips"; Krita Manual, Colorize Mask

## The idea
A Colorize Mask fills closed shapes with color. You paint a few strokes, and Krita fills the shapes around them. Revoy used it for his comic pages. He says: "10 minutes less on each panels means often many hours saved on a full story" (David Revoy, Krita Colorize-Mask: Advanced Tips).

## Look
In the Krita Manual, read the Colorize Mask page. The Colorize Mask Editing tool sits next to the Gradient Tool.

## Steps
1. Open ~/Art/Revoy/005-line-art.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/007-colorize.kra.
3. Click the lineart layer in the Layers docker.
4. Choose Add ‣ Colorize Mask for this layer.
5. Pick the Colorize Mask Editing tool.
6. Pick a red color. Paint one stroke inside a shape.
7. Pick a blue color. Paint one stroke inside another shape.
   You should see: Each closed shape near a stroke takes that color.
8. Add a stroke in a third color for a third shape.
9. Save the file.

## Check your work
- Does the Colorize Mask use strokes you paint? (Yes.)
- Must you fill each shape by hand? (No.)
- Does the tool need closed line art shapes? (Yes.)

## Make it yours
- Color a page with five shapes. Compare it with the Fill Tool.
- Paint a comic panel with three colors using strokes only.

## New words
- **colorize mask** — a Krita layer that colors shapes from strokes
- **stroke** — one line made by one drag of the pen
- **panel** — one box of a comic page
