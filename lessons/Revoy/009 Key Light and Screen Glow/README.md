# 009. Key Light and Screen Glow

**You make:** ~/Art/Revoy/009-light-glow.kra  (new file, copied from lesson 008)
**Builds on:** lesson 008
**Time:** 35 min
**Read:** David Revoy, "Overview of my Krita Digital Painting Workflow − end 2022", sections Shading and Post

## The idea
Revoy finds the key light first. The key light is the main light on a shape. Later he adds a glow layer in Screen mode. Screen makes bright light. He says a Screen layer can "simulate light coronas and other bloom effect" (David Revoy, Overview of my Krita Digital Painting Workflow).

## Look
In the overview, read the Shading part. Then find the Post part. Look for the word Screen.

## Steps
1. Open ~/Art/Revoy/008-shading.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/009-light-glow.kra.
3. Add a new paint layer on top. Name it key light.
4. Pick a warm yellow. Paint light on the top side of one shape.
5. Add another new paint layer on top. Name it glow.
6. Set the glow layer blending mode to Screen.
7. Pick a soft orange. Use b1) Airbrush - deevad 25. Paint a glow next to the bright edge.
   You should see: The glow adds light to the picture.
8. Lower the glow layer opacity if the glow is too strong.
9. Save the file.

## Check your work
- Does Screen make the picture brighter? (Yes.)
- Is the key light on the lit side? (Yes.)
- Do you need a 3D scene for light? (No.)

## Make it yours
- Paint a green glow around a bottle.
- Compare the same glow in Normal mode and in Screen mode.

## New words
- **key light** — the main light on a subject
- **Screen** — a blending mode that adds light
- **glow** — soft light around an edge
