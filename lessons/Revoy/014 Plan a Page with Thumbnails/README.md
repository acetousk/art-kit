# 014. Plan a Page with Thumbnails

**You make:** ~/Art/Revoy/014-page-thumbnails.kra  (new file)
**Builds on:** lesson 013
**Time:** 35 min
**Read:** David Revoy, "Episode 35 Production Report", section Thumbnails and values

## The idea
Revoy plans a page with small black and white thumbnails. He draws several key moments. Then he picks the strongest one. In his list, the first step is: "Black and White thumbnails enlarged" (David Revoy, Episode 35 Production Report).

## Look
In the production report, read the four numbered steps under Thumbnails and values. Count the steps.

## Steps
1. Press Ctrl+N. Make a new file, 1600 by 2200 pixels, tall.
2. Pick the Rectangle Tool. Draw four boxes on the page.
3. Pick b3) Basic Oval Brush - deevad 25. Use black only.
4. Draw one key moment inside each box.
   You should see: Four small, simple scenes.
5. Pick the Text Tool. Type a number in each box.
6. Pick the box with the strongest moment.
7. Erase the other three boxes with a1) Eraser Tip - deevad 25.
8. Save the file with File ‣ Save As. Use ~/Art/Revoy/014-page-thumbnails.kra.

## Check your work
- Does Revoy make small thumbnails first? (Yes.)
- Is one key moment chosen before the details? (Yes.)
- Must thumbnails use color? (No.)

## Make it yours
- Plan four panels for a short story about your character.
- Draw the same scene as two thumbnails. Pick one.

## New words
- **thumbnail** — a small, rough version of a page or picture
- **key moment** — the most important point of a scene
- **values** — how light or dark each shape is
