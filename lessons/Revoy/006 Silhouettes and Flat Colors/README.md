# 006. Silhouettes and Flat Colors

**You make:** ~/Art/Revoy/006-flat-colors.kra  (new file, copied from lesson 005)
**Builds on:** lesson 005
**Time:** 40 min
**Read:** David Revoy, "Overview of my Krita Digital Painting Workflow − end 2022", section Color Flat; Krita Manual, Flat Coloring

## The idea
Revoy paints solid shapes first. These shapes are silhouettes. Then he locks the layer, so paint stays inside. He says: "I lock the opacity of the layer, so I can paint only inside the shapes" (David Revoy, Overview of my Krita Digital Painting Workflow). In Krita, the same lock is Alpha Lock.

## Look
In the overview, read the Color Flat part. It explains the flat color pass.

## Steps
1. Open ~/Art/Revoy/005-line-art.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/006-flat-colors.kra.
3. Add a new paint layer below lineart. Name it silhouette.
4. Pick b4) Basic Size Pressure - deevad 25. Paint solid shapes on silhouette.
5. Click the Alpha Lock icon on the silhouette layer row.
   You should see: Paint now stays inside the shapes.
6. Pick a flat color from the palette.
7. Pick the Fill Tool. Click inside each shape.
   You should see: Each shape has one solid color.
8. Show the lineart layer again.
9. Save the file.

## Check your work
- Does Alpha Lock keep paint inside the shapes? (Yes.)
- Is the line art above the flat colors? (Yes.)
- Must the flat colors be perfect? (No.)

## Make it yours
- Flat-color a fruit with three colors only.
- Paint a scene with four flat colors. Keep the shapes simple.

## New words
- **silhouette** — a solid shape with no inside detail
- **flat color** — one even color with no shading
- **Alpha Lock** — keeps paint inside the shapes of one layer
