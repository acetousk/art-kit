# 020. Project Finish a Revoy-Style Page

**You make:** ~/Art/Revoy/020-project-page.kra  (new file, copied from lesson 019) and ~/Art/Revoy/020-project-page.png (export)
**Builds on:** lessons 014 to 019
**Time:** 60 min
**Read:** David Revoy, "Overview of my Krita Digital Painting Workflow − end 2022", section Paint-over and Post; Krita Manual, File Menu

## The idea
Revoy finishes with a paint-over. Paint-over fixes stiff shapes and adds a natural look. Then he adds post effects, such as color balance and light. He says: "nothing replaces a manual paint-over pass to give a more organic look to those parts" (David Revoy, Overview of my Krita Digital Painting Workflow).

## Look
In the overview, read the Paint-over and Post parts. Count the post effects he names.

## Steps
1. Open ~/Art/Revoy/019-speech-bubbles.kra. Do not save over it.
2. Press File ‣ Save As. Use ~/Art/Revoy/020-project-page.kra.
3. Add a new paint layer above the shading. Name it paint-over.
4. Pick b4) Basic Size Pressure - deevad 25. Paint over stiff edges on the characters.
5. Pick b1) Airbrush - deevad 25. Add soft shadows.
6. Choose Filters ‣ Adjust ‣ Color Balance on a new layer above all.
7. Move the sliders a little. Keep the change small.
8. Add a glow layer in Screen mode, as in lesson 009.
9. Hide the sketch layer. Zoom out to see the whole page.
10. Save the file with File ‣ Save As.
11. Choose File ‣ Export. Save a PNG as ~/Art/Revoy/020-project-page.png.
   You should see: One PNG image of the finished page.

## Check your work
- Does paint-over make stiff shapes look natural? (Yes.)
- Does Revoy add post effects at the end? (Yes.)
- Is the .kra file the master file? (Yes.)

## Make it yours
- Make a second page with a new subject and three panels.
- Make a one-panel poster from the same finished page.

## New words
- **paint-over** — a final pass that fixes and refines shapes
- **post effect** — a change made after the painting is done
- **export** — save a copy in another file type, such as PNG
